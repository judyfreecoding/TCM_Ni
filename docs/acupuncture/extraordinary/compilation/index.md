# 奇经八脉

## 十五络

十二经各有一络，为十二络；任脉络鸠尾，督脉络长强，脾之大络大包，合为十五络。

大包总统诸络。

::: danger 十五络的穴道

手太阴肺经络列缺，手阳明大肠经络偏历

手少阴心经络通里，手太阳小肠经络支正（治身上皮肤上生疣多）

手厥阴心包经络内关，手少阳三焦经络外关

足太阳膀胱经络飞扬，足少阴肾经络大钟

足少阳胆经络光明，足厥阳肝经络蠡沟

足阳明胃经络丰隆，足太阴脾经络公孙

任脉络鸠尾，督脉络长强，脾之大络大包
:::

络有病时，全身感觉到处都痛，胸前整个都痛，或者整个后背都痛，说不清是哪条经络的问题。

## 任督冲带



||任脉的运行|
|---|---|
|任脉在体前行于体表，在体后行于督脉内。|![An image](/compilation/1任督脉.png)|


督脉的阳气源于曲骨，也就是小便的地方。

任脉和冲脉起于胞中。胞中就是指女子的子宫、男子的精宫。膀胱和小肠之间有一个带状的缝隙，就是精宫的所在。
![An image](/compilation/2任冲起源.png)

::: info 月经和胡子
女子的奶水顺任脉下行到子宫，排出体外，就是月经。

男子的精液残渣顺任脉上行到口唇，排出体外，就是胡子。
:::

::: tip 精液为红色是何原因？
最纯的精血会送入精宫之中，是红色的，从精宫进入睾丸，因为睾丸在体外，由于精宫和睾丸的温差大，精血就由红色变为白色。所以精液是白色的。如果精液是红色的，说明精宫和睾丸的温差不够大，也就说明小肠的温度低了，说明小肠火不够了。
:::

胞中的病都属于任脉。所以治妇科病可用任脉和冲脉。因为任脉和冲脉同起源于胞中。

横膈前面络鸠尾，后面络第十一椎。我们下针就下在第十椎下，将将在横膈上。横膈属于心包系统。
![An image](/compilation/5心气止于膈.png)

::: tip 心气郁结
当心气有郁结时，我们扎天突、巨阙、关元。扎完以后，心气会集中到背后第十椎下，趴过来扎第十椎下，郁气就会从这里散出去。
:::

带脉在十四椎处，横向一圈，临床上看实际是三圈。临泣一个穴就治带脉的所有病。

::: danger 任督冲带的穴道
任脉：列缺

督脉：后溪

冲脉：公孙

带脉：临泣
:::

## 阴跷阳跷

::: danger 阴跷阳跷的穴道
阳跷：申脉。

阴跷：照海。	
:::

阳跷起于申脉，向上行于胆经和膀胱经的中间，一路到头。所以如果病人腿痛在胆经和膀胱经中间，是阳跷的问题。如果病人指不清楚具体是哪里痛，就胆经、膀胱经、阳跷脉一起治。

::: tip 后溪申脉，专治后项强痛
后溪申脉一组，专治后项强痛。
:::

阳跷的郄穴是附阳。中风病人脚往外翻，是阳跷的问题；脚往内翻是阴跷的问题。

阴跷起于照海，行于腿内侧，向上与冲脉并行，一路到咽喉。

::: tip 列缺照海，治一切喉病
由于任脉和阴跷都到咽喉，所以列缺和照海治一切喉病，如扁桃腺发炎、甲状腺功能亢进、慢性喉头炎，针一下，痛当场去掉。
:::

跷脉管行动。抬腿、左转右转、前行后行，就是跷脉在管。往前行是阳，往后退是阴；往外翻是阳，往内翻是阴。这些问题都是在阳跷或阴跷上治。针或灸都行。

## 阴维阳维

::: danger 阴维阳维的穴道
阳维：外关

阴维：内关	
:::

阳维围腑，所有的腑都与阳维是通的。阳维围胸腔肋骨外围。如果有人胸一圈痛、腰一圈痛，就下外关临泣。

阴维围脏，所有的脏都与阴维是通的。在外关引到气后直透到内关，就是打通生死桥。阴维围胸腔肋骨内部内脏一圈。如果病人说胸痛，要问是痛在肋骨里面还是肋骨外面，里面是阴维，外面是阳维，说不清楚就外关透内关。
