# 奇经八脉合集

如果将人体视为一棵树，那么树根就是肾藏，由树根再生出十二经络。经络像树干粗枝。
::: info 生病的原因
病有外因内因。<br>
外因：风寒暑湿燥热。外来的邪先入络，再入经，再入腑，再入藏。每天早晨起床吹嘘呼呵咝，把藏内的毒都排出去，那么外来的病邪最多走到腑，到不了藏。<br>
如果根有问题，树会生病；如果枝叶感受邪出现了问题，也会传导进来使树生病。<br>
所以常常护肾，是让根强壮，树就不容易生病；<br>
所以常常运动，是让树枝强壮，不易感邪，树也就不容易生病。<br>
内因：喜怒忧思悲恐、饮食。
:::

整个经络学的重心，就是藏和腑。肾决定人的寿命，肾藏护好，人就长寿。

## 十五络

十二正经是十二条大的树枝，旁边还有十五条较小的树枝，就是十五络。<br>
十二正经的络，加上鸠尾（任脉络）、长强（督脉络）、大包（脾之大络），合为十五条络。大包总统所有的络。<br>

### 1 心气止于膈

![An image](/compilation/1心气止于膈.png)
横膈前面络到鸠尾，后面络到第11椎（如果扎针，就钆在第10椎下，这样针尖就落在第11椎）。心藏将将在横膈之上，所以中医认为，心气止于膈。膈是心包的一部份。<br>
第11椎，也就是最下面一根肋骨。最下面一根肋骨，是12椎，但11椎的凸起，正好盖在12椎上，所以最下面那根肋骨所平对的脊椎突起，是11椎的凸起。

::: tip 治疗心脏病
治疗心脏病，前面下天突巨阙关元，扎完以后，翻过来扎第10椎下，因为前面扎完以后，心气会聚集在第10椎下，也就是横膈上，扎这里，就是让郁气从这里散出去。
:::

::: info 膈属于心包
心包膜和膈，是心包；<br>
所有藏器的包膜和全身遍布的皮下油网和肌肉包膜，都属于三焦。
:::

::: info 络病的表现和治疗
络有病时，全身都痛，或整个胸前都痛，或整个背都痛，分不清是哪条经痛，就是络的问题，下大包；<br>
络脉虚时，百节尽纵，就是全身松驰，没有劲，握不了拳，大包都治。<br>
络穴虚实皆治，下针手法是：虚则实之，实则虚之。也就虚证用补法，实证用泻法。
:::

## 任督冲脉

![An image](/compilation/2任督脉.png)
督脉，全身的阳气都在督脉汇聚，所以称督脉是阳之海。督脉脉气的起源是在曲骨处，也就是小便的地方。<br>
任脉在前走在体表，在后走在督脉内侧。任脉是诸阴之海。正由于任脉走在督脉内侧，所以背上有五藏的俞穴。<br>

![An image](/compilation/3任冲起于胞中.png)
任冲起于胞中。胞中，就是女人的子宫、男人的精宫。在小肠和膀胱之间。

![An image](/compilation/4精宫.png)
男人的精宫，在小肠和膀胱之间，是产生精液的地方。<br>
精液是白色的，奶水是白色的。奶水和精液是男女为繁衍后代而生成的最精华的物质。

![An image](/compilation/5奶水下行.png)
妇人的精就是奶水，奶水往下走，到子宫，残渣排出来，就是月经；<br>
男人的精就是精液，提练精液后产生的残渣往上走，走到口唇排出来，就是胡子。

![An image](/compilation/6白色精液的产生.png)
精就是最纯的养分。消化后产生的最纯的养分会由三焦汇集到精宫，精宫中的精液刚开始是黄色的，经小肠高温生化以后变成红色的精血，精宫中的精血排到睾丸之后，由于睾丸在体外，内外有温差，所以精液变成白色。如果小肠温度不够了，内外温差不大的情况下，精血排到睾丸就不会完全变成白色，而是掺杂着红色。所以如果排出来的精液里有很多血，那是因为小肠温度不够了。<br>
所以最纯的养分，平时是贮存在三焦中的，当人体有需要时，才立即汇集到精宫，开始生化精液的过程。并不是睾丸在产生精液。

![An image](/compilation/7任冲肾经.png)
任脉络到喉咙。<br>
冲脉和肾经是一起的。<br>
女人的子宫属于任脉，因为任起胞中。所以子宫的一切问题，都是在任脉治（列缺）。也可以在冲脉治（公孙），因为冲也起胞中。<br>
所以打坐练气都是要把气沉到胞中，目的就是要强肾强树根。<br>
冲脉是公孙在管（一说冲脉起于气冲，其实真正的源头是胞中）<br>
督脉是后溪在管<br>
任脉是列缺在管

![An image](/compilation/8冲脉经过胃心肺.png)
所以胃的问题、胸闷气喘、心痛、咳嗽，都可以用冲脉治（公孙）。冲脉的穴道和肾经的穴道是相同的。

## 带脉

带脉临床上看好像有三条，带脉是临泣在管。带脉起于季胁（也就是14椎），回身一周如带也。第一条在14椎横围一圈，第二条稍下一点，第三条再下一点。整个围着少腹。所以少腹胀满、冷痛、腰溶溶如坐水中，都可以用带脉治（临泣）。带脉有三个穴道，带脉五枢维道。但治疗带脉病，都只用临泣穴，临泣就可以根治带脉的病。

## 阴跷阳跷

阳跷脉，起于跟中外踝（申脉），一路顺着胆经和膀胱经的中间走上来，一直走到侧后项再到头部耳后。申脉管阳跷。郄穴是附阳。<br>
跷脉管动作，抬腿、左转、右转，就是靠跷脉。如果中风病人脚往外翻，说明阳跷脉是拉紧的，就是阳跷脉病了；如果脚往内翻，说明阴跷脉是拉紧的，就是阴跷脉病了。外八内八也是跷脉的问题，道理与外翻内翻一样。<br>
如果病人陈述腿痛，痛处是在胆经风市和膀胱经之间，这就是阳跷脉痛。如果病人一巴掌捂住大腿侧后方说这是痛处，那就胆经膀胱经阳跷脉一起下。<br>
老年人连续不停地讲同样的话，这是虚证。<br>
阴跷脉，照海在管。往前往后走也是跷脉在管。有病人往前走三步要退两步，这是阳急，说明阳跷脉是拉紧的，阳跷脉有问题；有的病人往前走一步要退三步，这是阴急，说明阴跷脉是拉紧的，阴跷脉有问题；还有病人一直往前走停不下来，要碰到障碍物才停得下来，这也是阳急，阳跷的问题。阳急治阳跷（申脉），阴急治阴跷（照海），下针也行，灸也行。<br>
这些奇怪的病都是在奇经上才有的，在正经上没有。<br>
阴跷脉起于内踝照海，一路上到咽喉，中间跟冲脉一路同行。所以咽喉的病，用任脉和阴跷治，也就是列缺和照海。不管是扁桃腺发炎，还是甲状腺功能亢进，还是慢性喉头炎，都可以治。特别是多年反复发作的慢性喉头炎，一下列缺照海，马上就感到喉咙舒服了不痛了。

## 阴维阳维

维脉，是把正经横贯联接在一起的脉，围在里面内脏上的是阴维，围在外面腑上的是阳维。阳维脉是外关在管。<br>
所有的腑跟阳维都是在随时互通信息的，所有的脏跟阴维都是随时在互通信息的。在外关下针，引到气之后，再把针透到内关，这就把阴阳脉连在一起了，生死桥就搭起了，阴阳就会交合在一起。<br>
阳维脉，是围着胸腔沿着肋骨外面一圈；带脉，是围着14椎以下季肋一圈。<br>
如果有病人，胸一圈痛，腰一圈痛，就下外关临泣一组；<br>
喉咙痛，就下列缺照海一组；因为喉咙是任脉和阴跷。<br>
项强脖僵，就下后溪申脉一组；因为后项主要是阳跷和督脉。<br>
阴维脉，是围着胸腔沿着肋骨里面一圈。所以病人陈述胸一圈痛，要问是肋骨里面痛还是肋骨外面痛。里面痛，内关；外面痛，外关；说不清楚，外关透内关。<br>
奇经八脉，都是一个穴道管一条脉。这一条脉上的病，都是这一个穴道治。
