# 针法

::: info 下针刺到血管怎么办？
如果刺到血管，鼓起一个包，用手轻轻覆上，平稳呼吸，六呼，包就平掉了。因为气会率血行。 
:::

## 引气

捻转引气法：下了针后就引气，左右捻转，观察气到没到。气到的特征：
- 病人感觉酸麻胀，就是气到了；
- 有的病人感觉痛，也是气到了；
- 针周围一圈粉红色，也是气到了。
- 针者感觉针很重着，像是被吸卷的感觉，也是气到了。

搓摩引气法：如果病人气弱，捻转了气还不到，可以在穴位上下皮肤表面轻轻搓几下，用医者的气去引导病人的气，气就到会。气行于表，所以只需在皮肤表面轻轻搓摩几下，不需用力按摩。

呼吸引气法：病人吸气，拨针，吐气，进针，几呼以后，会引到气。

如果以上方法都引不到气，起针，换灸。因为病人太虚了，气太弱了。

## 烧山火

里寒很重时，用烧山火手法。

把皮下一寸的距离分为三部，天人地，天部做9次紧按慢提，人部做9次紧按慢提，地部做9次紧按慢提，一共做27次。补气很强，会补得很热。
![An image](/needling/1烧山火.png)

::: warning 哪些穴道适合做烧山火？
比如胃寒痛呕酸，可在中脘上做，可在足三里上做。胃会马上热起来。
比如脚寒，可在三阴交上做。
肾寒，可在复溜上做，肾会马上热起来。复溜最好用灸，效果更好。盘腿，两个复溜一起灸。
:::

## 透天凉

病人大热、燥渴时，用透天凉手法。可以在尺泽上做。
针引到气后，先进到最底，在地部做6次紧提慢按，人部做6次紧提慢按，天部做6次紧提慢按，出针后不捂针孔。

::: warning 何时行补？何时行泻？
病人寒多热少，酸多痛少，先补后泻；扎完了母穴再扎子穴，也可以扎络穴或原穴，先做补再做泻。

热多寒少，或痛多酸少，先泻后补。

## 治痞

治痞远取穴法
留气法。用于肿块、痞块。比如硬块在乳房正中线，可知是胃经，可以在胃经的足三里、上巨虚、梁丘，都可以下针，行9次插提法，紧按慢提，做完以后，针刺到底，再提起豆许。这样气会很强，直冲上胸部，冲开痞块。然后在同一个穴位，再把气导引回来，就是行泻，行6次慢按紧提，做完以后，针刺到底，插下豆许，留针。起针后，不捂针孔。

治痞近取穴法。用于良性痞块，痞块表面光光，摸上去软软滑滑的。如果硬得像岩石，表面粗糙的，不可用此法。
一、烧针法。也叫燔针。使用时机，一是，脂肪瘤或黑痣，皮肤表面光滑，形状规则，这是良性。如果是恶性的，表面粗糙，形状不规则，摸着非常硬，不能用此法。二是，里面化脓，脓血很多，先用火罐拔，再用烧针刺，直对伤口刺进去。
烧针三针法：第一针，从上往下刺，第二针，从前往后刺，第三针，从后往前刺。就结束了。先沾麻油，针斜向下烧一下，再沾再烧，再沾再烧，如是三次，然后刺入。
![An image](/needling/2烧针三针法.png)

烧针三针治疗后，痞块第二天就小很多，最多再烧一次，就完全消了。一般两三厘米直径的痞块，烧一次，第二天就只有一点点了，再烧一次就没有了。痞块多长在背上、手腕阳池处、承扶处，突出的软骨也可用这种方法。
二、报刺法。又称飞针引气法。一手拉起痞块，一手下针，针尖到痞块底，左右捻针引气，然后提到皮层，然后分别向八个方向下针，到痞块边际，左右捻捻，如是八次，再提到皮层，再直下到底，左右捻捻，出针。这种方法，也是肿块第二天就消很多，只有一点点了。
![An image](/needling/3抱刺法.png)

对于没有脓疡的痞块，烧针法和报刺法功效一样，但对于有脓疡的痞块，只能用烧针法。

## 治疼痛

痛分为四种：
- 1、单纯的痛，这是实症，用泻法
- 2、痛多酸少，先泻后补
- 3、痛少酸多，先补后泻
- 4、酸麻。这是虚症，用补法。这个最不好治，要多治几次才好得到。

以上四种，一般先用子母补泻法，如果扎了子母穴，还有疼痛酸麻，就下原穴、络穴、本穴或郄穴，行补泻手法。以下运气法就是强泻的手法，提气法就是强补的手法。

运气法：这是强泻的手法，专治疼痛。逆快顺缓，行阴数6。
如果一个人足阳明胃经一带痛，或者乳中痛（也是胃经），可在对侧胃经下原穴冲阳，也可下郄穴梁丘，也可下络穴，补泻做完后针尖提至皮层，针尖对准痛的地方再进针，留针15、20分钟再起针，起针不捂针孔。

治疗顽固冷麻症
提气法
比如头部胆经痛，用临泣，做6数捻转，然后针提到皮层，针尖朝头再下。
