# 手少阳三焦经

## 时辰
亥时，PM9-11。晚9点，气血注入三焦经，开始三焦经的循行，直至11点。

## 三焦是什么

三焦就是脏腑外面、肌肉外面包裹的筋膜、油膜。你到市场上买牛腱，肉在中间，白白的那一层把它包着的，就是三焦。内脏包着很多的网，拉开来就是三焦。所以三焦无所不至。

三焦行阳。内经云，三焦，决渎之官，水道出焉；膀胱，州都之官，津液出焉。意思就是，三焦负责全身的水利，膀胱负责局部的津液。所以三焦是遍布全身的水网，腹胀水肿，是三焦的问题，水道不通，阳气不通，我们用行阳的方法让水道通畅，可以用手法行阳，可以下针行阳，也可以用药行阳，阳气一顺，水就不会累积。

::: tip 三焦治阴阳相争往来寒热
脏和腑之间的联络靠三焦。当邪在腑欲入脏而脏在御邪之时，中医称阴阳相抗，身体表现忽冷忽热，中医称往来寒热，这些症状都可以在三焦经上找到很好的穴道来治。
:::

# 三焦经穴道

## 关冲（井穴，属金，冬至后是母穴）

![An image](/triple_energizer/3关冲.png)
关冲，第四指外侧甲角。井穴，属金。

## 液门（荥穴，属水，冬至后是本穴）

![An image](/triple_energizer/4液门.png)
液门，第四指和第五指指掌骨节的后方，靠近关节骨头边。松握拳取穴。荥穴，属水，冬至后是本穴。

## 中渚（俞穴，属木，夏至后是母穴）

![An image](/triple_energizer/4液门和中渚.png)
中渚，液门下一寸，在骨缝中间。俞穴，属木，夏至后是母穴。虚症治此，在这里下针。书上说手不能伸屈下中渚，实际治疗中，遇中风手指不能伸屈，多用合谷透后溪，若是一般关节不能动，如扭曲不行，用三间透劳宫。

::: tip 眼科
液门、中渚，都可以治眼科，比如眼生白内障。这是因为三焦油网引起的问题，它们是三焦经的虚症。
:::

## 阳池（原穴）

![An image](/triple_energizer/5阳池.png)
阳池，在手的背面，腕关节正中有个凹洞。一般不灸，因为多汗。

::: tip 糖尿病消渴症
阳池透大陵，治消渴的著名穴道。
:::

如果系鞋带的地方有伤痛，就是解溪，对侧阳池下针，针一下去，痛当场去掉。这是对称治疗。反之，如果伤痛在阳池，就在对侧解溪下针。

## 外关（管阳维，络穴）

![An image](/triple_energizer/10支沟.png)
外关，阳池上两寸。管阳维。络穴。外关的对面就是内关。

::: tip 壮热高烧
外关透内关，通生死桥（治壮热高烧）：外关下针，引到气后再慢慢推到内关，这是将阳维三焦的阳气直接灌入阴维，一透拢，很快烧就退了。

可用于治小孩发高烧，小孩不留针，一透拢烧一退就出针。
:::

::: danger 手臂上下针的禁忌
手臂上扎针之后，手指不能乱动，否则牵拉臂上的筋，容易造成弯针。
:::

婴幼儿高烧不下针，用手法，称指针。指针手法如下：

::: tip 婴幼儿受惊吓
![An image](/triple_energizer/7baby受惊揉耳轮.png)
婴幼儿受惊吓，眉宇间会有青筋，会哭闹。轻揉双耳轮，揉到安静就可以停止了；

如果眼珠上吊，揉耳轮时下拉耳垂；

如果眼珠下垂，上拉耳轮；

如果眼珠斜向上，反向斜拉耳轮。

拉的时候，稍微用力一点揉耳朵，眼珠子就会回来。
:::

::: tip 婴幼儿手诊
![An image](/triple_energizer/8风关气关命关.png)
婴幼儿有病时，食指掌侧会出现青筋黑线，食指三节由根到尖分别名风关、气关、命关。

病初在表，青筋在风关；

病进入腑，青筋在气关；

病重入脏，青筋在命关。

中指和无名指也有三关。青筋或黑线在风关和气关，很好治，在命关，就非常难治。
:::

::: tip 背痛
![An image](/triple_energizer/9背痛的诊治.png)
痛在督脉，后溪；

痛在膀胱经，虚症扎委中，实症扎束骨；

横着痛，痛在肋间，这就是阳维痛，扎外关；

横着痛，痛在肚脐以下，就是带脉痛，扎临泣。
:::

## 支沟（经穴，属火，夏至后是本穴）

![An image](/triple_energizer/10支沟.png)
支沟，外关上一寸。经穴，属火，夏至后是本穴。

::: tip 便秘：支沟+照海
经验穴：支沟+照海（阴跷脉），治便秘。

便秘分寒症和热症，寒症是肠子不蠕动造成的，一周不大便也不痛不难受；热症是干造成的，大肠蠕动但大便出不来，所以痛。下支沟照海，不分寒热，下针之后24小时就会排便。

治便秘还可以四花灸（中脘关元天枢+神阙）。
:::

支沟，就是下水沟。阴道，也属于下水沟。所以大小便、女人难产、胎衣不下、漏下不止、任脉不通、不孕等等，都可以下支沟。

## 会宗和三阳络

![An image](/triple_energizer/11支沟会宗三阳络.png)
会宗，支沟外开一寸，在骨边。

三阳络，支沟上一寸。三焦经在支沟折转横向到会宗，再折回原线到三阳络。

::: tip 婴幼儿高烧重症：三阳络推经筋（加强版天河水）
小孩高烧重症（癫癎抽筋抽搐痉挛角弓反张脑膜炎）时，天河水都不够用了，这时就用经筋，从三阳络开始，三阳络的阳气很强，手法与天河水一样。在三阳络揉一下，让气血往下走，力量会非常强。推了阳之后，翻过来，推阴，也一样，三关不够用了，要推手腕以上的经筋，男，往上推是去寒，往下推是去热；女反。

- 寒症，是往上抽，角弓反张，是紧张，就往上推，推几下就松下来了；
- 热症，是瘫软无力，就往下推。

三阳络相当于加强版天河水，一般不用，只用在小孩重症高烧时退热去寒。
:::

三阳络有动脉，下针要小心避开动脉。三阳络气脉很强，声哑、耳聋，都可以用。外关和支沟用得多。

手六筋
现在说的是经筋，不是经络。经筋是用于指针术的。
肺经太渊经渠列缺旁边是心小肠筋，
中间心包经上边是脾胃筋，
下边是三焦心包筋，
心经阴郄通里灵道神门旁边是肾膀胱筋，
肾和三焦中间是肺大肠筋，
心和脾胃中间是肝胆筋。
手六筋指针术用于治婴幼儿病很有效。比如婴儿黄疸，就在肝胆筋上轻推，推的是气，所以一定要轻，在皮肤表面轻轻往上推；如果小儿吐奶，就在脾胃筋上轻轻往上推；小儿咳嗽，在肺筋上推；小儿大小便有问题，在肾筋上推。
推筋的原则是，由下往上推，是去寒；由上往下推，是去热。如何分寒热？小儿脸是赤红色，热；脸是青淡暗色，寒。
指针术的全过程是：先点外关开天河水，然后指针术推六筋，推到病退，再点间使散天河水。

和髎，耳门前半寸动脉旁。
耳门（三焦），听宫（小肠），听会（胆），这三穴都在耳屏前的骨缝中。都是近取穴治耳病，三穴可互换，临床中，治小孩耳朵流脓，今天扎耳门，明天扎听宫，后天扎听会，不要在同一个穴道上每天扎，扎太多针皮肤会硬成一块。治耳朵病，耳朵周围的穴道都可以用，具体用哪个？就看哪个有压痛，在压痛点下针。知道病在哪条经上，就在该经上找压痛点，在压痛点下针。
