# 十二正经总结

## 胸腹线路

![An image](/12Summarize/任肾胃脾胆胸腹线路.png)

胸肋部线路，从中间至两侧，依次为：任脉、肾经2寸、胃经4寸、脾经6寸、胆经。

腹部线路，从中间至两侧，依次为：任脉、肾经1寸、胃经2寸、脾经4寸、胆经。

## 背部线路

![An image](/12Summarize/膀胱经背部线路.png)

背部只有督脉和膀胱经。从中间至两侧，依次为：督脉、膀胱经寸半线、膀胱经三寸线。
