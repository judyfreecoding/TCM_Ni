# 足厥阴肝经


## 时辰

足少阳胆经的循行时间是半夜11点到1点。1点以后进入肝经。

胆经从足窍阴走到四趾根，再从脚掌趾根下面一路走到大趾趾根，再走到大趾甲角内侧的大敦，进入肝经。临床上看到很多人脚掌趾根一条线痛，就是胆经到肝经的络线的问题。
![An image](/liver/1胆经到肝经的走线.png)

肝经循行时间是1点到3点。当肝有问题时，会在这个时间段准时醒，到3点以后才能入睡。具体什么时间点醒，要看肝的问题具体在哪里。

::: info 用时间诊断肝的问题在哪里
![An image](/liver/2用时间诊断肝的病点.png)
在最右侧，1点醒；在中间，2点醒；在最左侧，3点醒。如果1:30醒，那么就在偏右侧。
:::

::: tip 用时间检验治疗处方是否正确
下针治疗后，从1:30醒变成2点醒，再变成2:30醒，说明病在退，治疗方案对了，再继续按原处方治，就变成接近3点醒，再后来通宵可以睡了，这就是治好了。

如果治疗后从1:30醒变成1点醒了，说明治疗方案错了，病在进，要改处方。
:::

临床上看，病人是因为全身发黄疸等原因去医院检查，而查出是肝癌或肝硬化，但病人都是在两年多前就夜里1点到3点醒3点以后才能入睡了。所以肝病在初，是夜里睡眠出问题，此时问题小，如果此时治，很容易治，不会等到变成肝癌肝硬化。如果针灸治疗，就是下肝经荥穴俞穴（行间太冲），还有肝俞肝募。悲胜怒，多悲伤一下，比如看一些悲情电视剧，就把情绪平衡了。

::: info 荥穴俞穴治时症
倪大师的恩师告诉他荥穴治时症；《针灸甲乙经》上说俞穴治时症。荥穴俞穴都有效。扎荥穴要痛些，俞穴比较不痛。

治时症时，可以换着扎荥穴俞穴，观察哪个更有效。也可以一起扎。
:::

人睡眠时间一天四五个小时，最多六个小时就够了，但睡眠要深。西方医学说一天要睡眠八个小时，其实人是不需要的。

## 肝色青

肝是青色。五色用在所有的地方，包括诊断、治疗、选药。青色营养本该藏在肝里面，如果青色跑到脸上，说明肝里面有实，占据了位置，把青色营养挤出来了，由于温高质轻向上升，所以出现在脸上。所以一看到脸色发青，就知道有肝实。

## 肝开窍于目

眼睛的问题都是肝的问题。肝经络到眼后，眼睛由肝统管，但眼睛还有四条小络，分别络心脾肺肾。所以无论眼珠是什么颜色，瞳孔都是黑色，因为肾经络到瞳孔。

## 酸入肝

天然酸，比如柠檬及其它水果的果酸，对肝有益；放久了腐烂的酸，也入肝，但它会伤肝。放半年了不腐烂，更不能吃，因为自然的东西一定会腐烂。

## 肝主筋

游泳运动容易抽筋，肝有问题；发癫癎全身崩紧，肝有问题。

## 肝声呼，音“嘘”

::: info 肝脏逼毒法
手捧肝脏，深吸气，再发“嘘”音吐气吐完，然后提谷道，再把身体中最后的气吐出。这样做是很有效的，做一次眼睛就会发亮，做三次眼睛会很亮。一天做三五次就够了。
:::

## 怒伤肝

生气会伤肝；反过来，肝有问题时，也很容易生气。这是一个恶性循环。

## 肝藏魂，心藏神，肺藏魄

神魂魄都要归位，人才能眠。整晚不能睡，心；1-3不能睡，肝；3-5不能睡，肺。

# 肝经穴道

## 大敦（井穴，属木，本穴）

![An image](/liver/3大敦.png)
大敦，井穴，属木，本穴。肝经是唯一一条绕阴器的经脉，所以既是井又是本的大敦治阴部病奇效。

::: tip 阴部病 = 大敦
治任何阴部的病，第一个想到的就是大敦。

- 疝气的时候，人就只想蹲下去，所以大敦治疝气奇效，右边的睾丸掉下来，扎对侧的大敦，一扎一痛，睾丸就缩回去了
- 倪大师治了一个睾丸不停旋转的人，下大敦，就好了。
- 其它阴部病，如疝气、子宫下垂、性病、阴部痛、小便痛、月经量多等
:::

## 行间（荥穴，属火，子穴）

![An image](/liver/4行间.png)
行间，一二趾掌骨端头后方。荥穴，属火，子穴。治肝家实症。一寸针足够。

肝实的表现：1-3不能睡觉，右肋痛，人全身发黄（这是肝病肝炎急性发作的表现）。还有睾丸痛、阴茎痛、妇人月经、阴道等等阴部的问题，通通可以下行间，都很有效。

## 太冲（俞穴，属土。治肝家时症）

![An image](/liver/5太冲.png)
太冲，一二趾掌骨之间，行间后一寸。俞穴，属土。治肝家时症。太冲是个很重要的穴道，是开四关的穴道之一。

::: info 开四关：太冲、合谷
- 开四关的意义。四关：太冲、合谷。同时针太冲合谷，叫做开四关。合谷主气，太冲主血。人左侧为血，右侧为气。太冲合谷同时下，就是气血兼顾，人体系统就会气血调合。
- 使用开四关的时机。病人觉得全身都痛，却又说不出具体哪里痛，这是由于病人有一两条病经痛，由于全身气血不合，所以病经引起了全身痛，全身痛就掩盖了病经的痛。这时下合谷太冲，一下，病人全身气血会调合，病人就会感觉痛处逐渐清晰了，比如痛在头侧，胆经；痛在后脑，膀胱经；痛在环腰一圈，带脉；这就可以针对具体的病经下针了。所以开四关最大的应用是抓贼。
:::

::: info 对称穴位：太冲、合谷
如果合谷处痛，扎对侧太冲。这是对称治疗。反之，太冲痛，扎对侧合谷。对称治疗，无所谓补泄，也没有虚实寒热之分。
:::

::: warning 肝病治疗最常用的穴道：行间、太冲
肝喜条达，肝以疏为补。所以肝经的子穴是使用最多的穴道。大部份的肝病都是因瘀因堵而起，所以都用行间来泻。

相距一寸的穴道，都有互补互助的作用，行间和太冲，也是一样。扎了行间，如果觉得效果还不够，就加扎太冲。最典型的病例是妇人漏下不止、月经不停。肝经是唯一一条绕阴器的经脉，所以阴器相关的病，行间太冲都可以治。也可以治小便带血。小便带血，原因很多，可能是膀胱结石、肾结石，也可能是肾脏肿瘤，还有治疗肝癌的时候，有一个时间会小便带血，那是肿瘤在排出来。因为肝经绕阴器而过。
:::

::: info 脚上三脉判断病况
脚上有三脉，指三动脉，太冲脉、冲阳脉、太溪脉。

太冲主血，人左侧为血，所以左脚太冲脉比较强，右脚太冲脉有时摸不到。太冲脉就代表肝脏；

冲阳脉在足阳明胃经，代表胃气；

太溪脉在足少阴肾经，代表肾脏。

有脉则生，无脉则死。
:::

## 中封（经穴，属金）

![An image](/liver/6中封.png)
中封，经穴，属金。和商丘隔一个大筋。用得不多。

## 蠡沟（络穴）

蠡沟，络穴。内踝上五，也就是三阴交上二。与光明相对。无论虚实，都可以下络穴。有的人吃了威尔刚后下不来，阳挺不下，那就是肝实，可以用络穴，或子穴，还可以泡冰水；肝虚的时候，皮肤痒。带“沟、谷”字的穴道，有瘀积的时候就可以用，比如少腹有积块。

## 中都（郄穴）

中都，蠡沟上二，也就是内踝上七。与外丘相对。

## 膝关

膝关，腘内侧横纹头，下针下在横纹头上五分。膝关和曲池的找法是一样的。治膝盖痛效果非常好。

::: tip 严重膝盖痛
当膝盖痛很严重时，下膝五穴四针再加膝关。效果非常好。
:::

## 曲泉（合穴，属水，母穴）

曲泉，合穴，属水，母穴。治肝家虚症。如皮肤痒、痉挛、阴挺不下、小便困难、失眠、子宫、少腹，尤其是阴痒，曲泉效果很好。

## 

阴包，曲泉上三寸。阴包，故名思义，就是膀胱，小便困难，原因可能是膀胱结石、肾结石、小肠太寒、尿道感染、月经不调，都可以用阴包。

奇穴：治肝三穴。大腿内侧从膝中高骨向腹股沟虚划一条线，线的正中间一点，中点前后一寸各一点，这三点，称为肝三穴，专治肝硬化肝癌。肝硬化肝癌病人，肝三穴有强烈压痛，但肝炎病人就没有，所以肝三穴可以诊断肝硬化肝癌。如果有强烈压痛，就在压痛点下针，一点痛下一点，两点痛下两点，三点都痛就下三点，左右都下，一寸半针就够了。大腿内侧有大动脉，所以不要扎太深，不要用三寸针，但一寸针扎不到，所以用一寸半针最合适。如果肝硬化病人很痛，除了下肝三穴外，可加左侧肝关（小肠经奇穴），还可加肝经郄穴；如果有肝腹水，可以扎下水三针（三阴交地机阴陵泉）和上水三针（水分水道）；如果没有胃口，可以灸中脘、关元；还可以灸膏肓100壮。方法有很多，自己去悟去试。怎么知道治没治好？身上黄退了，小便颜色正常了，晚上可以睡了，胃口正常了，肝三穴不压痛了。之所以肝硬化肝癌病人的肝三穴会有压痛，因为只有肝经经过这里，所以这里有压痛，说明肝经出了问题。
照上面方法治疗了之后，病人还没有回家煮药，已经感觉轻松了很多，好像好了一半。针灸效果是立杆见影的。

阴廉，气冲下二寸。曲骨外开二寸，是胃经的气冲，气冲在腹股沟腿侧的大腿根部。
五里，阴廉下一寸。
气冲、五里、阴廉，都是求子穴。只灸不针，因为动脉很多。

章门，侧面肋骨最下点。脏会章门，脏病治此。脾募章门，脾胰治此。这里一受击打碰撞，五脏气就乱了。下针，可以从前往后刺，也可以从后往前刺，参照肋间穴道的下针方法，不能直刺。也可以灸。
期门，章门这根肋骨不算，章门上面的两根肋骨之间是日月，再上两根肋骨之间是期门。肝募期门。下针，是顺着肋间斜刺，从任脉向外。也可以灸，一边看喜剧或悲剧一边灸。呕酸，是肝的问题，可以灸期门。女人月经时得了感冒即伤寒太阳表症，因为此时正是奶水下行至子宫再排出体外的过程，所以病毒会顺着奶水下行到子宫，这时就要马上针期门，也可以吃小柴胡汤，但针期门比小柴胡来得快，可以最快速地把病毒清出去。
肝病的治法，下肝募期门；同时要强脾，下脾募章门；再强水，下肾募金门。这样就能把肝的运行推回正道。倪治肝病，如果有腹水，是50%的治愈率，如果没有腹水，都治好了。
