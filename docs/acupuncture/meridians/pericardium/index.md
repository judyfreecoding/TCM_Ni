# 手厥阴心包经（PM7-9，戌时）

心包和三焦相表里。心包募膻中和三焦募石门，都在任脉上，一上一下，相互呼应。
![An image](/pericardium/4心包募和三焦募.png)

同样的设计概念：心募巨阙和小肠募关元，也都在任脉上，一上一下，相互呼应。

## 时辰

戌时，PM7-9。晚7点，气血注入心包经，开始心包经的循行，直至9点。

如果每晚7-9点这段时间心脏最不舒服，那就是按时间发的，叫做时症。按《针灸甲乙经》，下心包经俞穴，倪的老师教的是荥穴，都有效的。下荥穴要痛一些。

## 心包简介

心脏是君主之官，不受病，由心包代受病。心包就是心脏外面包的那一层膜。
![An image](/pericardium/1心包膜.png)

孕之初是一滴真水，那就是肾；一周后是肝；再一周是心。如果孕初两周因药物或情绪伤到真水，就会出现先天性心脏病。这两周如果保护得很好，心脏就不会有病。过了两周以后，就进入脾脏，心脏就定型了，不会受病了。
![An image](/pericardium/2先天性心脏病的原因.png)

中医认为，心脏的问题，都是心包的问题，是心包膜有问题才引起了心脏的问题。

心脏相火。因为心脏很热，像火一样，所以称为“相火”。心和小肠就是上下两个火。
![An image](/pericardium/3心和小肠是上下火.png)

## 心包属性

与肝心脾肺肾五大系统均有自己的固定属性不同，心包有双重属性。
![An image](/pericardium/3心包有两个属性.png)

夏至~冬至，心包经属性相火；

冬至~隔年夏至，心包经属性相水。夏天外面热，里面也热，为了避免身体过热，心脏会把热发散掉，所以流汗；冬天冷，体内的热需要内敛，心脏的热要全部集中传给小肠，所以心包属性相水以保温。

::: danger 心包的穴道穴性会随着季节变化

# 心包经穴道

## 天池

![An image](/pericardium/5天池和天泉.png)
天池，乳中外开一寸。妇人乳房硬块在乳中外开一寸的地方，就要选心包经的穴道下针，或者天应灸；只有在喂乳期间是不管硬块的经络，只治阳明胃经（如解溪梁丘）和心（心募心俞），以确保母乳全力下行，避免多余的奶水积在乳房里面。

## 天泉

天泉，在胸部，腋横纹头下两寸。就是乳房的外上角。同样，如果乳房硬块出现在天泉这里，也是选心包经的穴道来治。

## 曲泽（合穴，属水，冬至以后是本穴）

|||
|---|---|
|![An image](/pericardium/6大筋外侧是尺泽.png)|肘窝大筋前面是尺泽|
|![An image](/pericardium/7大筋内侧是曲泽.png)|肘窝大筋后面是曲泽|
|![An image](/pericardium/8尺泽和曲泽.png)|尺泽和曲泽|

曲泽，合穴，属水。在冬至以后，心包经属水，所以此时曲泽就是本穴，代表这条经。

如果委中委阳痛，在对侧尺泽曲泽下针，这就是对称治疗法。

心主汗，如果中风中脏病人有舌强不能语症状，知道是他心脏有问题（心开窍于舌），吃药后发了一点点汗了，就证明心脏功能恢复了；还没有发汗，就是还没有恢复，就继续吃药。

## 郄门

![An image](/pericardium/9郄门.png)
郄门，又作隙门，心包经郄穴。腕横纹上五寸，如图在两条大筋的中间。心痛可下针，郄穴镇痛止痛的效果是很好的。

::: info 手六筋
![An image](/pericardium/10手六筋.png)
大指侧的筋，也就是肺经旁的筋，是心小肠筋（赤筋）；紧靠心筋旁的小筋，是肝胆筋（青筋）；然后是中间两条大筋，靠大指侧的脾胃筋（黄筋），靠小指侧的是三焦筋；小指心经旁的是肾膀胱筋；在肾筋和三焦筋的中间还有一条小筋，是肺大肠筋。
:::

## 间使（经穴，属金，冬至以后是母穴）

![An image](/pericardium/11大陵内关间使郄门.png)
间使，腕横纹上三寸。经穴，属金，冬至以后是母穴。专治手麻：同侧间使，对侧大陵。

## 内关（络穴、阴维）

![An image](/pericardium/11大陵内关间使郄门.png)
内关，腕横纹上两寸。络穴。管阴维。可止吐，可催吐。指压内关，神思“想吐”或“不想吐”，效果很明显。下针，治胃心胸，治吐、心口痛（胁骨里面痛）、气喘，配合公孙效果更佳。
::: tip 公孙内关胃心胸
- 胃痛，先下公孙内关，一下针，胃就不痛了，再下足三里、中脘这些；
- 心肌梗塞心绞痛，先下公孙内关，再下关元巨阙天突（心三针）；
- 气喘，先下公孙内关，再下中府云门肺俞这些。
:::

## 大陵（俞穴，属土，夏至以后是子穴）

![An image](/pericardium/11大陵内关间使郄门.png)
大陵，腕横纹。俞穴，属土，夏至以后是子穴，治实症，比如乳房硬块在天池或天泉，且痛拒按（可能超过五天，但只要是痛拒按，就是实症，通通下子穴），就可下大陵。

::: warning 大陵下针方式
斜向手掌下针，对着劳宫穴下针，和神门下针方式一样。
:::

::: tip 脚后跟痛
![An image](/pericardium/12大陵相脚后跟.png)

::: info 天河水：治婴儿发烧、惊厥、眼斜
大陵内关间使郄门这一段可以行指针手法，叫天河水，治婴儿发烧、惊厥、眼斜。三焦经再详讲。
:::

## 劳宫（荥穴，属火，夏至后是本穴）

![An image](/pericardium/15劳宫.png)
劳宫，握拳，中指尖和无名指尖的中间，就是劳宫；从解剖上看，就在三指掌骨和四指掌骨的中间；从外表看，就在手掌的正中间。荥穴，属火，夏至后是本穴。

## 中冲（井穴，属木，夏至后是母穴，冬至后是子穴）

![An image](/pericardium/16中冲.png)
中冲，中指尖。井穴，属木，夏至后是母穴。补井当补合，用曲泽当母穴作补用。泻井当泻荥，用劳宫当子穴作泻用。

中冲是井穴，可以退烧。心包络直接络到喉咙的舌后。中医说心开窍于舌，肾开窍于耳，肝开窍于目，肺开窍于鼻，脾开窍于唇。除了内脏以外，最主要就是因为有心包络跟三焦络夹在中间，所以内脏与外面的器官是相互连到的。
