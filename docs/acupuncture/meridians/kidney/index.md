# 手少阴肾经（阴水，PM 5-7 酉时）


## 时辰

下午5-7点，是气血流注于肾经的时间。五点钟以后，气血从至阴进入肾经，首先是涌泉穴。有的人每天下午到黄昏就开始累，7点以后眼睛亮了，就是肾的问题。

## 肾主骨
## 肾其华在发

头发光亮润泽，是肾水足的表现。人在死前两天或三天，肾气要绝了，头发整个会蓬起来，干枯没有光泽。

## 肾开窍于耳

耳鸣、耳聋、耳朵有问题都是在肾脏治疗。

## 肾主记忆

肾气在50岁时是巅峰，之后下降。节欲（一切欲望）护肾。
![An image](/kidney/2肾气50为巅峰.png)

::: info 先天性心脏病的由来
![An image](/kidney/3受胎之后.png)
受胎之后，人的第一个脏器是肾脏。胎儿是由一滴水开始的（西医称受精卵，中医称一滴真水），一周后化出筋膜，这就是肝，再一周后，化出心跳。
西药进入身体，都会将身体内的水释放掉。所以西医知道怀孕之后不能吃西药。先天性心脏病，就是受胎后吃了西药，因为妈妈不知道已受胎。西医方式知道怀孕已是两周后的事，若这两周内吃了西药，就已经伤到真水了。保险的方法是，如果决定要怀小孩了，就不要再吃西药了。可以用灸来替代。
:::

## 肾是作强之官，技巧出焉
研究研发创新的动脑思考，都是靠肾脏。

## 肾主二便
所以肾脏有问题的人，大便不正常，小便也会尿频。我们可以从很多地方得到肾的讯息。

## 肾主纳气
肾主纳气，即吸气，肺主呼气。

::: tip 气喘的区分
如果气喘病人是吸气困难，有耳鸣，黄昏很累，就是肾有病，都不需要摸脉。落脏落对了，我们下手一击即中。我们治肾，按阴阳五行都是先治火。

吐气困难，全身骨节酸痛，那就是肺的问题。因为肺主至节，肺主呼气。

对于气喘，西医不分吐气吸气，都开类固醇，这是把肺扩张的药，但是伤肾，脸会肿很大，类固醇用多了骨头会烂掉。
:::

## 其音羽，其声吹，其数6。

::: info 肾脏逼毒法
用吹声逼毒。站好，一脚前，一脚后，身体前倾，身体要弓起来，手压背后肾脏，吸一口气，然后发“吹”声吐气。气吐完后，才是开始，这时把肛门提起来，最后再发出无声的“吹”用力吐完最后的气。吐气完会发一身汗。
:::

# 肾经穴位

## 涌泉（井穴，属木，子穴）
![An image](/kidney/6涌泉.png)
脚底人字纹的顶端，就是涌泉穴。

涌泉穴。井穴，属木，肾经子穴。治肾家实症。泻井当泻荥，找然谷。

下针直进，涌泉下针很痛。倪师只在治头顶痛诸般无效时才下涌泉。比如撞到头顶了，很痛，后溪扎了，百会扎了，束骨扎了，还是痛，就下涌泉，一下，立刻止痛。

::: tip 肾病的望诊
![An image](/kidney/7肾病的望诊.png)
眼袋是肾的位置，眼袋暗粉红色，是肾病，且肾已经克到心了；眼下有一条卧蝉，是有积水。
:::

::: info 眼诊法
|正常人的眼睛|眼里的五脏|
|---|---|
|![An image](/kidney/8眼诊法.png)|眼内眦的那一点红，代表心<br>眼白，代表肺<br>瞳孔，代表肾<br><br>瞳孔外面一小圈，代表脾。称为土轮<br>土轮大约占黑眼珠的三分之一。<br>土轮纹路很细密，一条条排列整齐。<br><br>脾外面一大圈，代表肝。称为木轮<br>木轮大约占黑眼珠的三分之二。<br>木轮像木栅栏，一片片排得很整齐。<br><br>肝脾肾合起来，就是黑眼珠<br>任何人种的瞳孔都是黑的。<br>瞳孔越小的人越聪明，也说明肾好。|

***

知道了正常眼睛的纹路，一旦这纹路改变了，就可以判断出五脏的情况：
- 如果眼白上有白色一块一块的，这就是肺癌的表现，再一问睡眠如何，得知每晚三点准时醒来，这就是肺癌确诊了。
- 如果瞳孔变大，土轮跟到变大，木轮变小且有很多破洞，就说明水出了问题，反侮到了土，土又反侮到了木。
- 当灯光照上去，瞳孔马上缩小，这是正常；如果瞳孔不动，就是肾阳不够了。
:::

## 然谷（荥穴，属火。郄穴）。

![An image](/kidney/9然谷.png)
然谷，公孙后一寸，骨和肌肉的中间。

荥穴，郄穴。属火，代子穴用，治肾家实症。所以然谷很好用。

::: warning 然谷放血治脑震荡
然谷放血，是著名的撞伤治疗方法。

撞伤或摔伤后，如果有脑震荡，然谷这里的青筋会崩起来，放血针一刺，血就喷出来。这里放血后，脑震荡的症状如头昏头痛脑子不清晰等就去掉了，如果还有恶心呕吐，下公孙。
:::

## 太溪（俞穴，属土）

![An image](/kidney/10太溪.png)
太溪，在内踝高骨与脚后大筋的中间凹陷处。俞穴，属土。太溪里面有动脉，人昏迷过去，如果太溪脉还在，就是肾气还在，就可以救回来；如果曈孔放大，太溪脉也没有了，就没有救了。

附，冲阳脉在，就是胃气还在。

太溪下针，直下。

## 肾结石反应区（奇穴）

太溪上一两寸的范围，想像一个肾的形状，这就是肾结石的反应区。在这个区域按压，如果有强烈压痛，就是有肾结石，因结石点不同，所以压痛点会不同，在压痛点下针，直下。肾结石在排的时候很痛，一下针，痛马上缓解，过一会儿，病人会感到有东西在动，就是结石在排。吃钙片会长肾结石，还有注意饮水的问题。喝鱼骨汤就能很好补钙。人体需要钙，但只能从自然的食物中获取。

## 大钟（络穴）

![An image](/kidney/13大钟.png)
大钟，络穴。在后跟骨与大筋的交接处。肾实小便排不出、虚症腰酸痛，都可以下大钟。直下。

## 水泉（郄穴）

![An image](/kidney/14水泉.png)
水泉，郄穴。太溪向下到跟骨边上。从上到下斜向里下针。水、溪，都治水肿、月经等水病。治后跟痛，左脚后跟痛扎右脚水泉，右脚后跟痛扎左脚水泉。

## 照海（阴跷脉）

![An image](/kidney/15照海.png)
照海，内踝下五分的骨缝中。从上到下斜向里，顺着骨缝下针。

照海管阴跷脉。阴跷和肾经重叠并行至喉。

::: tip 列缺照海治一切喉病
列缺照海治一切喉病，如甲状腺肿大、扁桃腺发炎、慢性喉炎、咽炎。一下对穴道，喉痛马上去掉。如果扁桃肿得太大，三寸针天应放血，再下照海，喉痛当场去掉。后用夏枯草五钱，煮带壳鸡蛋，两碗水煮成一碗，喝汤吃蛋，之后终生不会再犯扁桃腺炎。
:::

::: tip 女人逆经
女人逆经，月经本该顺任脉下行，却被阴跷倒推上行，从鼻子出来，每月固定流鼻血，这就用照海治。
:::

::: tip 癫痫
- 癫痫夜发灸照海；

- 癫痫昼发灸申脉。

日灸九壮或更多，有空就灸。不用担心上火，灸脚是不会上火的。直至眼中鸡爪退尽。
:::

## 复溜（经穴，属金，母穴）

![An image](/kidney/16复溜.png)
复溜，太溪上两寸。经穴，属金，母穴。治肾家虚症。

::: warning 复溜的下针法
![An image](/kidney/17复溜下针法.png)
下针方式：在复溜下五分入针，斜向上进针，确保针尖停在复溜处。这是补针的下法。一下就是小补，下了针再随经捻转就是中补，再提豆许就是大补。

复溜下针的时候，常常会被麻或电一下。
:::

::: info 养生灸关元、复溜
平常没事看电视时，就灸灸关元、复溜，是很补人的。因为肾是水经，而艾就是找水的，所以一灸，脚就会热起来。脚只要是热的，脚上的水是汽化的，身体就不会累积多余的水，癌就不会作怪。我们每个人都有癌细胞，只要水是热的，它永远不会作怪。
:::

## 交信

![An image](/kidney/18交信.png)
交信，复溜往前一寸，到骨边，下针时不要太靠近骨边，因为会伤到骨膜。阴跷郄穴。肾经在复溜打了个折，横行到交信，然后再向上行。

交信用得不多，主要用复溜。没事灸复溜，非常好。一灸脚就热起来，水就流动起来。

## 筑宾

![An image](/kidney/19筑宾和曲池.png)
筑宾，太溪上五后一。阴围脉郄穴。

::: tip 筑宾、曲池、委中 -- 皮肤病大穴
筑宾和曲池上下呼应，消炎解毒镇痛，筑宾管肚脐以下，曲池管肚脐以上。

- 如果上半身痒，下合谷曲池，因为合谷是气脉；
- 下半身痒，下筑宾血海三阴交。
- 如果是牛皮癣，委中放血。
五穴十针，左右都要下，下针的同时，全身的痒就去掉了。所以这五个穴加上委中，是治疗皮肤病的大穴。
:::

::: info 巨阙和关元，上纪和下纪
巨阙是上纪，管肚脐以上的纪律和循环；关元是下纪，管肚脐以下的纪律和循环。
:::

## 阴谷（合穴，属水，本穴）

阴谷，腘内侧两条筋的中间凹洞。属水，本穴，合穴。可泻金家实症，比如肺和大肠的实症，可用阴谷去泻。可补木家虚症，比如肝胆虚症，可用阴谷去补肝胆。本穴，可补泻子母，这就是本穴的用法。下针方法：曲腿下两筋中间的凹洞，直腿下筋的内侧，因为腿直起来的时候两条筋就崩成了一条筋。只要扎下去引到气，水性就出来了，就补木泻金了。所以本穴无所谓行补泻。

对称治疗法：如果委中痛，可以扎对侧委中，或者扎对侧尺泽或曲泽；如果腘窝内侧痛，可以扎对侧少海；如果外侧痛，扎曲池；如果肘尖撞痛，可以扎对侧鹤顶；如果腕背中间痛，扎对侧解溪；如果太渊痛，扎对侧商丘；如果鱼际痛，对侧然谷或公孙。

横骨，曲骨外开一寸。腹部肾经与任脉相距一寸。腹部肾经与冲脉重叠。胸腹部的穴道一般是近取穴，近取穴配合远取穴效果更好。比如失精梦遗，可以近取横骨，远取太溪、复溜。
