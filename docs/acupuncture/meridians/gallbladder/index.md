# 足少阳胆经（阳木）（PM 11-1 子时）

## 时辰

夜11点，气血从三焦经的耳门和髎走到司竹空，然后从司竹空下行进入胆经的瞳子髎，开始胆经的循行。

半夜11点到1点是气血在胆经流注的时间。总是这个时间醒来，或是睡不着，或是其它的一切问题，都是胆的问题。

## 胆经简介

胆，阳木。胆与肝相表里，肝为阴木。之所以说肝是木，是因为肝在人体中的作用和树木在自然中的作用是同样的。粪便浊水施给树木，树木吸收后长出果实来；身体里的脏水流给肝，肝把它转化成果实后交给心，这就是阴木生阴火，同时肝生产后排出的浊水交给胆，就是胆汁，胆汁流入小肠，帮助小肠消化食物，这就是阳木生阳火。
![An image](/gallbladder/1木生火的由来.png)

::: info 胆的问题和切胆的后果
心包膜有一条神经直接络到胆上，所以心脏的速度会传递给胆，胆汁喷出的频率和心脏的跳动是一致的。如果胆汁喷不出来了，那么就是心的力量不够了。所以治疗胆就很简单了，加强心脏的力量，同时用药把胆里的浊物清出来，再加强肝的代谢，让它多一点胆汁给胆，从后面去推胆，就结束了。如果用西医的方法，把胆切掉，那么肝的废水会堆积在总胆管中，临床上看，切后15年，总胆管会变成一个极硬的硬块，被称为肝结石。
![An image](/gallbladder/2切掉胆的后果.png)
:::

在头临泣这里，是胆经和膀胱经最靠近的地方。头临泣距离督脉大约一寸半，发际后一寸半；

而膀胱经，是在前发际从眉冲横行至一寸半的曲差，曲差后一寸是五处，五处后一寸半是承光。膀胱经始终与督脉是一寸半的距离。

也就是说，头临泣在五处后半寸。从头临泣往后，就沿着头侧向头后走线，与膀胱经逐渐偏离。

## 瞳子髎

瞳子髎，是胆经第一个穴道，就是太阳穴，眼后半寸眼骨旁的凹洞。下针扎半寸，多用于放血。下针主要是近取穴治太阳痛。

::: tip 眼翳
![An image](/gallbladder/4眼翳的诊断.png)
眼翳，要看眼翳是从哪里生的。
- 如果是从眼头生的，那是来自睛明的湿热，治膀胱经，近取穴就扎睛明；
- 如果是从眼尾生的，那是来自瞳子髎的湿热，治胆经，近取穴就扎瞳子髎；
- 如果是从眼下生的，那是来自承泣的湿热，治胃经，近取穴扎承泣；
- 如果是从眼上生的，那是来自阳白的湿热，治胆经，近取穴扎阳白。
:::

## 听会

耳门（三焦）听宫（小肠）听会（胆经），都是张口取穴。

直下针，不捻针，只插提。

::: tip 耳鸣
耳鸣，有来自内力和来自外力两种，如果是不知道怎么就耳鸣了，那是来自内部的肾虚，治则补肾，同时在经络上取穴；如果有明确原因的，比如潜水上浮得太快了，出水就有了耳鸣，这个治疗就是在原地方再潜一次，然后慢慢上来，耳鸣就去掉了；还有听音乐声音太大得了耳鸣，也是回原地方声音同样大，然后慢慢慢慢把声音小下来，一次就好了，都不需要下针。
:::

## 曲鬓

曲鬓，耳根上角外侧，在动脉旁边。
含厌到曲鬓，分三等份，中间两点上为悬颅，下为悬厘。治头痛的时候，在这里找到压痛点就下针。偏头痛就在这一带。

率谷，耳尖往上一寸半。非常好找，有个骨缝。太阳透率谷，治疗偏头痛立杆见影。头痛的时候，就是透针最好的时机，一透拢，立刻就不痛了。太阳透率谷手法：针下瞳子髎，捻一捻，引到气，然后把针尖回到皮层，针倒下来，另一手把皮提起来，一路透到率谷，是从皮下透，很容易透的。如果没有针，从太阳一路按到率谷，也是有用的。

完骨，在耳垂后一寸半，头骨边上五分的位置。从率谷到完骨的路线，与耳朵形状一致；在完骨处开始折返向上，沿着更大的耳朵形状一路到本神、阳白。

阳白，眼中正上方，眉毛和发际的正中间。阳白的下针方法，提起皮肤，从阳白进针，针尖透到鱼腰。

头临泣，眼中正上方，发际上一寸半，有个骨缝。头临泣和目窗，治眼病效果很好，比如迎风流泪。

目窗，头临泣往后一寸半。
正营，目窗后一寸半。
承灵，正营后一寸半。
脑空，承灵后一寸半。
风池，在耳后大筋后面，头骨下五分处的凹洞中。针尖对准对侧颧髎（颧骨）进针，不会碰到任何血管。风池可治对侧鼻子不通。
风池风府风门，治后项强硬。可刮痧，可拨罐。

肩井穴，缺盆骨在肩上的最高点，两片肌肉的中间。在肩膀的正中间。一寸针，下五分，不能下深了，凶。捻转引到气就行，肩井的气很强。肩井必须配对侧足三里，否则气会结在胸腔里。肩井配对侧足三里，是有名的治血胸的大穴。跌打损伤，血积胸中，称为血胸。血胸时，病人喘不过气，胸痛。下了肩井足三里后，气就喘得过来了，后会排出黑色大便，那就是把瘀血排出来了。
后项连带肩强硬、酸。用后溪（管督脉）、申脉（外踝下五分，管阳跷），然后再下肩井、足三里，几乎可以去掉所有的肩项酸痛。
孕妇不能下肩井，因为肩井气很强，气会向下冲，可能导致落胎或伤害胎儿。

外伤大穴：脑震荡，然谷放血；跌打损伤血胸，肩井配足三里。

渊液，极泉下三寸。胆经从肩井过肩前，绕到腋下。极泉下三寸是胆经，极泉下六寸是大包，是脾经。
辄筋，渊液往前一寸。
日月，胆募。期门向下隔一个胁骨。期门，巨阙旁开四寸。胆经从辄筋到日月，是绕着乳房外侧外围走的。下期门日月，一定要摸到肋骨，针要下在肋骨间，才能下准。下针时，由内侧向外侧沿着肋骨间扎。

俞募治疗法。募，就是开口开门。俞，就是运输疏通。如果胆汁不通堵了，扎日月胆俞。

京门，肾募。肋骨最下的一点，叫章门；从章门往后摸，摸到下一个肋骨尖，就是京门。直下针，一寸针就够了。配肾俞，治肾病如腰酸耳鸣。

带脉五枢维道，是带脉的三个穴道。章门往下约一寸八分，在两个肌肉中间，是带脉穴。关元外开七寸半，是五枢；中极外开八寸，是维道。
腰痛，如果是脊椎两旁上下痛，是膀胱经；中间痛，是督脉；环腰一圈痛，带脉。
西医的椎间盘突出造成坐骨神经痛，这从中医经络学上来说是不成立的，不符合人体经络布线。所以按照西医的治疗方法手术之后仍然痛。要看痛在哪条经络，治相应经络，才能治好。

华陀夹脊，沿着督脉旁开五分。如果腰痛在华陀夹脊，用足三里（胃本）+临泣（胆本）治疗。这是经验穴，极效。书上没有记载。

居髎，章门下八点三寸。
环跳，骨之始。大腿骨的根部。点环跳穴都很痛。腿弯起来才有环跳。三寸针，扎到骨边，不留针，捻转引到气，叫病人吸气，一边吸一边拨针，他吸气的时候气就会进入环跳穴，吸完之后针不动，等他吐气，吐气完后，进针；再吸拨针，再吐进针；如此三呼三吸就出来。这叫呼吸补泄法。
新骨细胞从环跳开始生长。骨病刚开始时，一定是环跳痛。如果环跳痛，就扎环跳，用三呼三吸法，扎一次就不痛了，说明是单纯的神经痛；如果扎两次三次都还痛，说明是骨病了，就要用治骨病的方法。如果环跳痛，穿着牛仔裤不方便扎环跳，就扎对侧肩髃。环跳是下肢根部，肩髃是上肢根部，正好对称。环跳也可作为骨病的诊断穴，如果环跳不痛了，说明骨病治好了。环跳是中风瘫痪大穴。

风市，也是中风瘫痪大穴。膝中向上七寸，差不多是一卡长。深针，要扎到骨边。膝盖无力站不起来，用风市+阴市。

中渎，风市下两寸。风市的助力穴。

阳关，就是侧面的膝中缝，也叫膝关。很浅，下半寸就酸了。
阳陵泉，小腿根部外侧两个骨端为两点，画一个等边三角形，第三点就是阳陵泉。筋会阳陵。也是中风瘫痪大穴。治膝盖痛，有著名的五穴四针，即双膝眼、鹤顶、阳陵透阴陵，五穴四针的效果与五穴五针（即阳陵阴陵各一针，不透针）的效果就不一样。合穴，属土。

胆石点，阳陵泉下一寸。这是奇穴。胆结石的人，在胆石点会有压痛，在这里下针，胆结石痛就会去掉。这里从痛治到不痛，就说明胆结石已经排出来了。下一寸半针就好。可以配胆募胆俞。很好用。
肾石点，在交信和太溪中间，也就是太溪上一寸。肾结石的人，在肾石点会有压痛，在这里下针，肾结石痛就会去掉。这里从痛治到不痛，就说明肾结石已经排出来了。
盲肠点，足三里下一寸。盲肠炎的人，在盲肠点会有压痛，在这里下针，盲肠炎痛就会去掉。这里从痛治到不痛，就说明盲肠炎已经好了。

所以小腿是检查全身的最好用的地方之一。倪大师是通过小腿检查全身有没有病，周老师也是通过小腿检查全身有没有病。

阳交，外邱向后旁开一寸。胆经从阳陵泉向下稍斜后方走线，走到阳交，再横行至正中线的外邱，然后直行向下。胆经在外邱阳交这里有个横折弯，所以有的人痛在小腿胆经处会出现横折弯痛。手臂上三阳络的地方会折个弯。阳交是阳维脉的郄穴，阳维的郄穴是上七横一，阴维的郄穴是上五横一。

外邱，治犬咬伤。外踝直上七寸。被犬、蛇、蜂、蛛咬伤，都是一样处理，先在咬伤处（牙痕上），用隔姜灸，灸三壮，灸完伤处，再灸外邱。外邱是胆经络穴，而肝是解毒的，所以外邱治咬伤中毒。

光明，也是络穴，外踝上五寸，在胫骨前侧，下针直下。胫骨前侧是胆经，胫骨后侧是膀胱经，靠近前面骨头的就是胃经。治眼病，常用眼周的睛明、承泣、四白、瞳子髎、丝竹空，手上三焦的养老，脚上胆经的光明。

阳辅，外踝上四寸。经穴，属火，子穴，治胆家实症。由下往上下针，是为泄，在阳辅下半寸进针，才能确保针尖扎到阳辅穴上。

悬钟（绝骨），外踝上三寸。髓会绝骨。三寸是个大致的说法，每个人的绝骨不一样，正确的找穴法是，从外踝顺着骨头往上摸，摸到骨头好像断了的地方，那就是绝骨。绝骨越高，脑容量越大，人越聪明。髓会绝骨，所以骨髓生病，在绝骨会有压痛。绝骨也是中风瘫痪大穴（风市阳陵绝骨）。
中风有中脏中络，中脏就是中在深处，表现为不能讲话；中络就是中在表，表现为表皮肌肤不仁。所以中脏就下深针，中络就下浅针。针都下风市阳陵绝骨，只是深浅不同。中脏就下深针，风市下到骨边，阳陵透阴陵，绝骨透三阴交（要透到在三阴交看得到皮下的针尖）；中络就浅针，下在表皮进去一点就行。

八会穴
髓会绝骨、骨会大杼、筋会阳陵
血会隔俞、气会膻中、脉会太渊
脏会章门、腑会中脘

丘墟，原穴。专治脚踝扭伤，商丘透丘墟，不是从骨缝中间穿过去，是从两条大筋下面穿过去，一寸半针就够了。胆家虚实都治。如果眼翳是从上往下生的，就是胆经的湿热气，除了近取阳白外，还可以下丘墟。阳经都有原穴，就是因为原穴是三焦经与六阳经交汇的点，三焦油网遍布全身，完全行阳，原就是指阳的源头，这个阳源，来自三焦。

临泣，主带脉。脚背上，小脚趾往外一拉，四趾五趾骨间会出现一条斜筋，筋的后面，骨缝间，就是临泣。腰横着一圈痛，下临泣，痛当场去掉。如果除了腰一圈痛，背上华陀夹脊也痛，那么下临泣+足三里，痛当场去掉。俞穴，属木，本穴。所以临泣即可以治胆经的病，比如眼病，比如乳房肿块在胆经上；又可以治带脉的病，比如腰痛；还可以治胆经时症，比如11点半、12点以后发的病，因为临泣是俞穴；还可以治水和火的病，可用于泄水和生火。临泣的用途非常多。

地五会，斜筋的前面，就是地五会。地五会是很好的治疗乳房硬块的大穴。地五会也治脚皮特别干。

侠溪，四五趾掌骨端头间。荥穴，属水，母穴，治胆家虚症。下针的时候，在侠溪前五分入针，顺经刺入，为补。比如偏头痛，痛了几年了，下侠溪，只要扎对了，效果很好；还有耳鸣，除了肾虚引起的耳鸣治肾以外，还有胆经、三焦经、小肠经都经过耳朵，所以耳朵的问题都可以下针这些经络；还有眼睛的问题，眼上是阳白，眼尾是瞳子髎，都是胆经。

足窍阴，四趾外侧甲角。井穴，属金。小趾外侧甲角是膀胱经的至阴。井穴效果是最好的，如果眼睛痛，是从外眼侧痛，下窍阴就有用；如果从眼内侧痛，就要下至阴，因为那是睛明痛；从眼睛下方痛，就要下厉兑才有用。头昏眼花、昏迷，都可以下井穴。临床上下井穴都用小针，一寸针或五分针，在井穴下针或放血。井穴平常很少灸，要灸也可以。

胆经从四趾下面络到大趾，这一段就是胆经到肝经的路线，肝经从大趾开始，一点以后进入肝经。
