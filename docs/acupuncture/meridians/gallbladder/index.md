# 足少阳胆经（阳木）（PM 11-1 子时）

## 时辰

夜11点，气血从三焦经的耳门和髎走到司竹空，然后从司竹空下行进入胆经的瞳子髎，开始胆经的循行。

半夜11点到1点是气血在胆经流注的时间。总是这个时间醒来，或是睡不着，或是其它的一切问题，只要是这个时间段固定出现的问题，都是胆的问题。

## 胆经简介

胆，阳木。胆与肝相表里，肝为阴木。之所以说肝是木，是因为肝在人体中的作用和树木在自然中的作用是同样的。粪便浊水施给树木，树木吸收后长出果实来；身体里的脏水流给肝，肝把它转化成果实后交给心，这就是阴木生阴火，同时肝生产后排出的浊水交给胆，就是胆汁，胆汁流入小肠，帮助小肠消化食物，这就是阳木生阳火。
![An image](/gallbladder/1木生火的由来.png)

::: info 胆的问题和切胆的后果
心包膜有一条神经直接络到胆上，所以心脏的速度会传递给胆，胆汁喷出的频率和心脏的跳动是一致的。如果胆汁喷不出来了，那么就是心的力量不够了。所以治疗胆就很简单了，加强心脏的力量，同时用药把胆里的浊物清出来，再加强肝的代谢，让它多一点胆汁给胆，从后面去推胆，就结束了。如果用西医的方法，把胆切掉，那么肝的废水会堆积在总胆管中，临床上看，切后15年，总胆管会变成一个极硬的硬块，被称为肝结石。同样一个片子，三个内科医生可能会有三个读出结果，分别是肝肿瘤、肝硬化、肝结石。
![An image](/gallbladder/2切掉胆的后果.png)
:::

有个小孩阅读有困难，他把b看成d，原因是他小时候吐奶很厉害，把胆囊吐得反过来，所以就“视物倒之”，不是上下倒，而是左右倒。

临床上看，呕吐、口苦，都是胆的问题。

# 胆经穴道

胆经的头部线路和穴道：

![An image](/gallbladder/3胆经头部走线和穴道.png)

::: danger 头部的经络分布

![An image](/gallbladder/3督脉膀胱胆经在头部的走线.png)
- 沿耳朵的一圈（没有头发），是三焦经
- 头正中间是督脉
- 督脉旁开一寸是膀胱经。攒竹距督脉约半寸，攒竹直上入发际是眉冲，眉冲旁开一个眉冲到督脉的距离为曲差。曲差距督脉一寸，天柱距督脉约一寸半，从曲差到天柱，膀胱经是从一寸到一寸半渐变
- 再旁开半寸，以及这整个头侧和耳外一圈，都是胆经。眼中距督脉约一寸半，阳白、头临泣、目窗，都在眼中一条线上，距督脉一寸半，风池距督脉大约二寸，从头临泣到风池，胆经是从一寸半到二寸渐变

胆经在耳后与三焦经联络。

这是最准确的头部经络布线说明。前面倪大师讲膀胱经距督脉一寸半、再开一寸半是胆经，都属口误。另外，古书中写膀胱经距督脉一寸半，是因人各有异，在一寸、一寸二分、一寸半之间都有之，以找穴为准。

头部大致的布线距离以此图为准。
:::



## 瞳子髎

瞳子髎，是胆经第一个穴道，就是太阳穴，眼后半寸眼骨旁的凹洞。下针扎半寸，多用于放血。下针主要是近取穴治太阳痛。

::: tip 眼翳
![An image](/gallbladder/4眼翳的诊断.png)
眼翳，要看眼翳是从哪里生的。
- 如果是从眼头生的，那是来自睛明的湿热，治膀胱经，近取穴就扎睛明；
- 如果是从眼尾生的，那是来自瞳子髎的湿热，治胆经，近取穴就扎瞳子髎；
- 如果是从眼下生的，那是来自承泣的湿热，治胃经，近取穴扎承泣；
- 如果是从眼上生的，那是来自阳白的湿热，治胆经，近取穴扎阳白。
:::

## 听会

耳门（三焦）听宫（小肠）听会（胆经），都是张口取穴。

直下针，不捻针，只插提。

::: tip 耳鸣
耳鸣，有来自内力和来自外力两种，如果是不知道怎么就耳鸣了，那是来自内部的肾虚，治则补肾，同时在经络上取穴；如果有明确原因的，比如潜水上浮得太快了，出水就有了耳鸣，这个治疗就是在原地方再潜一次，然后慢慢上来，耳鸣就去掉了；还有听音乐声音太大得了耳鸣，也是回原地方声音同样大，然后慢慢慢慢把声音小下来，一次就好了，都不需要下针。
:::

## 率谷

率谷，耳尖往上一寸半。非常好找，有个骨缝。

::: warning 偏头痛
![An image](/gallbladder/8太阳透率谷.png)
太阳透率谷，治疗偏头痛立杆见影。头痛的时候，就是透针最好的时机，一透拢，立刻就不痛了。

太阳透率谷手法：针下瞳子髎，捻一捻，引到气，然后把针尖回到皮层，针倒下来，另一手把皮提起来，一路透到率谷，是从皮下透，很容易透的。

如果没有针，从太阳一路按到率谷，也是有用的。虽然没有透针那么有效，但也能缓解一些。
:::

::: info 倪大师治偏头痛的临床经验
有一个病人头痛二十五年，他吃西药一天要吃二十二颗，先吃止痛药，因为止痛药会伤肝，所以另外一颗药要预防它伤肝，但是预防伤肝的药又会伤肾，所以又要吃预防伤肾的药，而预防伤肾的药又会伤心脏，他又要吃保护心脏的药。所以加起来一天要吃二十二颗。最后西医叫他停药，不然肝肾都完蛋了。

然后他没办法了，来找倪大师。早上来的时候倪问他“现在头痛不痛？”答不痛。倪让回去，等痛的时候再来。当天下午就来了，抱着头进来的。倪让躺下。先在合谷下一针，这是麻醉；然后太阳透率谷。一透拢，痛当场止掉了。

扎完回家，叫他下次痛再来。三天后他又来了，进来时很高兴地说，现在的痛只有以前的20%了，好了80%。再下第二次透针。

两次扎完，从1996年11月到现在（估计是2010年），没有再痛过。他很后悔吃了二十五年的止痛药。
:::

从率谷到完骨的路线，与耳朵形状一致；在完骨处开始折返向上，沿着更大的耳朵形状一路到本神、阳白。

## 阳白

![An image](/gallbladder/9阳白.png)
阳白，眼中正上方，眉毛和发际的正中间。阳白的下针方法，提起皮肤，从阳白进针，针尖透到鱼腰。阳白透鱼腰，治眼睛近视，视物不明，眼睛痛，白内障。白内障眼翳是从上面往下生的，就在阳白透鱼腰。

有的病人，头痛就痛在阳白，就知道他是胆经痛，在胆经子母穴下针。

## 头临泣和目窗

![An image](/gallbladder/10头临泣.png)
头临泣，眼中正上方，发际上一寸半，有个骨缝。头临泣和目窗，是眼科大穴，治眼病效果很好，比如迎风流泪，一下针，就会减轻很多。

目窗，头临泣往后一寸半。

## 正营承灵脑空

正营，目窗后一寸半。

承灵，正营后一寸半。

脑空，承灵后一寸半。

主要治头痛、头昏眩。

## 风池

![An image](/gallbladder/12风池风府风门.png)
风池，在耳后大筋后面，头骨下五分处的凹洞中。

::: warning 风池的下针方法
因为风池在颈部，扎到里面的动脉很危险，所以风池的下针方法有讲究。

病人趴下，头摆正。下针的时候，先用一只手按到对侧颧髎，另一只手按风池，假想一条线。针尖对准对侧颧髎（颧骨）进针，不会碰到任何血管。
:::

::: tip 鼻窦炎、鼻子不通
风池治对侧鼻子不通。只要下对了穴位，针一下去，鼻子就通了。
:::

::: tip 后项强硬
风池风府风门，是身体的窗户，是受风的地方。一受到风寒，就会项强。

风池风府风门，治后项强硬。除了下针，还可刮痧，可拨罐。
:::

::: info 风门
风门，在二椎下旁开一寸半。是治痈疽的要穴。方法是灸风门。
:::

## 肩井

![An image](/gallbladder/13肩井.png)
肩井穴，缺盆骨在肩上的最高点，两片肌肉的中间。在肩膀的正中间。

肩井穴是武术家的禁忌点，如被重击，人会被打昏。

肩井穴对于针灸家来说，也是一个特殊的穴位，下针不能下太深，下太深的话，人会昏厥。

::: danger 肩井下针要点
- 一寸针，下五分，不能下深了，凶。
- 捻转引到气就行，肩井的气很强。
- 肩井必须配对侧足三里，否则气会闷在胸腔里。
- 孕妇不能下肩井，因为肩井气很强，气会向下冲，可能导致落胎或伤害胎儿。
:::

::: tip 跌打损伤，血瘀胸中
跌打损伤，血瘀胸中，称为血胸。血胸病人喘不过气、胸痛。肩井配对侧足三里，是有名的治血胸的大穴。下了肩井足三里后，气就喘得过来了，后会排出黑色大便，那就是把瘀血排出来了。
:::

::: tip 肩项强硬酸痛
后项连带肩膀强硬、酸痛，用后溪（管督脉）、申脉（外踝下五分，管阳跷），下针以后，痛就去掉一大半。若还有一点痛，再下肩井、对侧足三里，几乎可以去掉所有的肩项酸痛。
:::

::: info 外伤急救大穴
- 脑震荡，然谷放血；脑震荡病人，有呕吐头昏等症状，然谷处会有一个积块，在积块处一放血，症状立刻去掉；
- 跌打损伤血胸，肩井配足三里。血胸病人，有胸痛、喘不过气症状，下肩井和对侧足三里，马上就可以喘气了。
:::

## 渊液

渊液，极泉下三寸。胆经从肩井过肩前，绕到腋下。极泉下三寸是胆经，极泉下六寸是脾经的大包。

如果是腋下三寸这里痛，就知道是渊液，是胆经的问题；

如果是腑下六寸的地方痛，就知道是大包，是脾经。

## 辄筋

辄筋，渊液往前一寸。

## 日月（胆募）

![An image](/gallbladder/14日月.png)
日月，胆募。期门向下隔一个胁骨。期门，巨阙旁开四寸。胆经从辄筋到日月，是绕着乳房外侧外围走的。

::: warning 期门日月下针方法
下期门日月，一定要摸到肋骨，针要下在肋骨间，才能下准。下针时，由内侧向外侧沿着肋骨间扎。
:::

::: warning 俞募治疗法
募，就是开口开门。俞，就是运输疏通。如果胆汁堵塞不通了，扎日月胆俞。
:::

## 京门（肾募）

肋骨最下的一点，叫章门；从章门往后摸，摸到下一个肋骨尖，就是京门。直下针，一寸针就够了。配肾俞（命门外开一寸半），治肾病如腰酸耳鸣，用得很多。

## 带脉五枢维道

![An image](/gallbladder/15带脉五枢维道.png)
带脉五枢维道，是带脉的三个穴道。

章门往下约一寸八分，在两个肌肉中间，是带脉穴。

关元外开七寸半，是五枢；

中极外开八寸，是维道。

::: info 带脉病
腰融融如坐水中。就是好像坐在冷水中的感觉。
:::

::: tip 腰痛

- 腰痛，如果是脊椎两旁上下痛，是膀胱经；虚用委中，实用束骨
- 中间痛，是督脉；后溪
- 环腰一圈痛，带脉痛。临泣
- 华陀夹脊，沿着督脉旁开五分。如果腰痛在华陀夹脊，用足三里（胃本）+临泣（通带脉）治疗。这是经验穴，极效。足三里和临泣一下，华佗夹脊的痛就去掉了。书上没有记载。倪大师是给一个练气功的师兄扎足三里和临泣，师兄告诉他扎了之后气就从督脉两旁往上升，由此发现了足三里+临泣治疗华佗夹脊痛的方法。
![An image](/gallbladder/16华陀夹脊.png)

西医的椎间盘突出造成坐骨神经痛，这从中医经络学上来说是不成立的，不符合人体经络布线。所以按照西医的治疗方法手术之后仍然痛。要看痛在哪条经络，治相应经络，才能治好。
:::

居髎，章门下八点三寸。用得不多。

## 环跳

![An image](/gallbladder/17环跳.png)
环跳，骨之始。新骨细胞从环跳开始生长，长出之后，由环跳开始向四肢末梢行进，从环跳到四肢末梢，骨细胞要走两年。所以人是每两年换一次全新的骨骼。

所以骨病刚开始时，一定是环跳痛。反过来，如果环跳痛，那么有两个可能，一是单纯的经络痛，一是骨病。

::: warning 环跳的找法
![An image](/gallbladder/17环跳的找法.png)
环跳在大腿骨的根部。腿弯起来才有环跳。摸到大腿骨的尽头，手握拳抵住腿骨根部，大姆指到处是穴。在这里按一下，如果病人大叫一声，那就找对了。点环跳穴都很痛。
:::

::: warning 环跳的下针法
三寸针，扎到骨边，不留针。先捻转引到气，然后叫病人吸气，一边吸一边拨针，他吸气的时候气就会进入环跳穴，吸完之后针不动，等他吐气，吐气完后，进针；再吸气拨针，再吐完进针；如此三呼三吸就出来。这叫呼吸补泄法。
:::

如果环跳痛，就扎环跳，用三呼三吸法，扎一次就不痛了，说明是单纯的神经痛；如果扎两次三次都还痛，说明是骨病了，就要用治骨病的方法。

如果环跳痛，穿着牛仔裤不方便扎环跳，就扎对侧肩髃。环跳是下肢根部，肩髃是上肢根部，正好对称。

环跳也可作为骨病的诊断穴，如果治到环跳不痛了，说明骨病治好了。

环跳是中风瘫痪大穴。

:::

## 胆石点

![An image](/gallbladder/21胆石点.png)
胆石点，阳陵泉下一寸。这是奇穴。胆结石的人，在胆石点会有压痛，在这里下针，胆结石痛就会去掉。这里从痛治到不痛，就说明胆结石已经排出来了。

::: warning 胆石点下针
下一寸半针就好。
:::

可以配胆募胆俞。很好用。

::: info 小腿上的反应点
- 肾石点，太溪上一寸。肾结石的人，在肾石点会有压痛，在这里下针，肾结石痛就会去掉。这里从痛治到不痛，就说明肾结石已经排出来了。
- 盲肠点，足三里下一寸。盲肠炎的人，在盲肠点会有压痛，在这里下针，盲肠炎痛就会去掉。这里从痛治到不痛，就说明盲肠炎已经好了。
- 胆石点，阳陵泉下一寸。
- 眉棱点，阴陵泉下一寸。

所以小腿是检查全身的最好用的地方之一。倪大师是通过小腿检查全身有没有病，周老师也是通过小腿检查全身有没有病。
:::

## 阳交（阳维郄）

![An image](/gallbladder/22外邱阳交.png)
阳交，外邱向后旁开一寸。胆经从阳陵泉向下稍斜向后方走线，走到阳交，再横行至正中线的外邱，然后直行向下。胆经在外邱阳交这里有个横折弯，所以有的人痛在小腿胆经处会出现横折弯痛。手臂上三焦经的支沟也是横折到会宗，然后再回到正途三阳络。

阳交是阳维脉的郄穴，阳维的郄穴是上七横一，阴维的郄穴是上五横一。

## 外邱（络穴，治咬伤中毒）

外邱，外踝直上七寸。外邱是治犬咬伤的穴道。因为狗咬到大部份在外丘这里。

::: tip 咬伤处理
被犬、蛇、蜂、蛛咬伤，都是一样处理，先在咬伤处（牙痕上），用隔姜灸，灸三壮，灸完伤处，再灸外邱。外邱是胆经络穴，而肝是解毒的，所以灸外邱会让身体的解毒力量加强。
:::

## 光明（络穴）

![An image](/gallbladder/23光明.png)
光明，也是络穴，外踝上五寸，在胫骨前侧，下针直下。

治眼病，常用眼周的睛明、承泣、四白、瞳子髎、丝竹空，手上三焦的养老，脚上胆经的光明。

::: info 小腿上胆胃膀胱经的走线
腓骨前侧是胆经，腓骨后侧是膀胱经，靠近前面胫骨的就是胃经。
:::

## 阳辅（经穴，属火，子穴）

![An image](/gallbladder/24阳辅下针的方向.png)
阳辅，外踝上四寸。经穴，属火，子穴，治胆家实症。由下往上下针，是为泄，在阳辅下半寸进针，才能确保针尖扎到阳辅穴上。

## 绝骨（髓会）

![An image](/gallbladder/25阳辅绝骨.png)
悬钟（绝骨），外踝上三寸。髓会绝骨。三寸是个大致的说法，每个人的绝骨不一样，正确的找穴法是，从外踝顺着骨头往上摸，摸到骨头好像断了的地方，那就是绝骨。绝骨越高，脑容量越大，人越聪明。髓会绝骨，所以骨髓、脑髓生病，在绝骨会有压痛。绝骨也是中风瘫痪大穴。

::: info 腿上的三个中风瘫痪大穴
风市、阳陵泉、绝骨

中风有中脏中络之分，中脏就是中在深处，表现为不能讲话；中络就是中在表，表现为表皮肌肤麻木不仁。所以中脏就下深针，中络就下浅针。针都下风市阳陵绝骨，只是深浅不同。中脏就下深针，风市下到骨边，阳陵透阴陵，绝骨透三阴交（要透到在三阴交看得到皮下的针尖）；中络就浅针，下在表皮进去一点就行。
:::

::: info 八会穴
骨会大杼、髓会绝骨、筋会阳陵

血会隔俞、气会膻中、脉会太渊

脏会章门、腑会中脘
:::

## 丘墟（原穴）

![An image](/gallbladder/26邱墟.png)
丘墟，原穴。胆家虚实都治。

::: tip 脚踝扭伤
商丘透丘墟，专治脚踝扭伤。不是从骨缝中间穿过去，是从两条大筋下面穿过去，一寸半针就够了。
:::

如果眼翳是从上往下生的，就是胆经的湿热气，除了近取阳白外，还可以下丘墟。阳经都有原穴，就是因为原穴是三焦经与六阳经交汇的点，三焦油网遍布全身，完全行阳，原就是指阳的源头，这个阳源，来自三焦。

## 临泣（主带脉。俞穴，属木，本穴）

![An image](/gallbladder/27临泣.png)
临泣，主带脉。俞穴，属木，本穴。脚背上，小脚趾往外一拉，四趾五趾骨间会出现一条斜筋，筋的后面，骨缝间，就是临泣。腰横着一圈痛，这是带脉痛，下临泣，痛当场去掉。如果除了腰一圈痛，背上华陀夹脊也痛，那么下临泣+足三里，痛当场去掉。

::: warning 临泣的四大用途
- 临泣是胆经本穴，可以治胆经的病，比如眼病，比如乳房肿块在胆经上。只要是胆经经过的地方，通通可以用临泣；
- 临泣主带脉，可以治带脉的病，比如腰痛；
- 临泣是胆经俞穴，可以治胆经时症，比如11点-1点之间定时发的病；
- 临泣是胆经本穴，可以代表木，所以可以治水和火的病，可用于泄水和生火。

所以临泣用得非常多。
:::

## 地五会

![An image](/gallbladder/28地五会.png)
地五会，斜筋的前面，就是地五会。因为胆经从肩井一路斜向下到腋下三寸渊腋，再向前一寸到辄筋，再向斜下到日月。这中间是经过乳房外侧的。当乳痈长在胆经经过地的时候，地五会是很好的治疗乳房硬块的大穴。地五会也治脚皮特别干。

## 侠溪（荥穴，属水，母穴）

![An image](/gallbladder/29侠溪.png)
侠溪，四五趾掌骨端头间。荥穴，属水，母穴，治胆家虚症。下针的时候，在侠溪前五分入针，顺经刺入，为补。

::: warning 侠溪治胆家虚症
- 偏头痛，痛了几年了，下对侧侠溪，只要扎对了，效果很好；
- 耳鸣，除了肾虚引起的耳鸣治肾以外，还有胆经、三焦经、小肠经都经过耳朵，所以耳朵的问题都可以下针这些经络；
- 眼病，眼上是阳白，眼尾是瞳子髎，都是胆经。
:::

## 足窍阴（井穴，属金）

足窍阴，四趾外侧甲角。井穴，属金。小趾外侧甲角是膀胱经的至阴。

::: tip 眼睛痛
用井穴效果是最好的。眼睛痛，是从外眼侧痛，下窍阴就有用；如果从眼内侧痛，就要下至阴，因为那是睛明痛；从眼睛下方痛，就要下厉兑才有用。临床上下井穴都用小针，一寸针或五分针，在井穴下针或放血。
:::

头昏眼花、昏迷，都可以下井穴。

井穴平常很少灸，要灸也可以。

胆经从四趾下面络到大趾，这一段就是胆经到肝经的路线，肝经从大趾开始，一点以后进入肝经。

## 胆经胸腹线路图

![An image](/gallbladder/30胆经胸腹穴道.png)

图中将渊腋辄筋并为一点，是因为渊腋在极泉下三寸，辄筋在渊腋前一寸，从正面看，渊腋和辄筋就并为一点，都在极泉下三寸。

从肩井到渊腋辄筋，再到日月，胆经绕着乳房外侧从上至下走线，所以乳痈、乳房包块如果在胆经线路上，就从胆经找穴位治疗。

## 乳房的经络分布图

![An image](/gallbladder/31乳房的经络分布.png)

正中线是任脉。乳中线是胃经。乳中线与任脉的正中间是肾经。乳中线外开二寸是脾经。脾经外开约一寸是胆经。

所以从中间往两边的垂直线路依次是，任脉、肾经、胃经、脾经、胆经。

另外，心包经从乳中外开一寸到乳外上角腋横纹头下方，是一条斜线。
