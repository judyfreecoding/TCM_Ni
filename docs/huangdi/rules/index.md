## 四季的刺法（出自 61、水热穴论）

春取络脉；因为春天是风病，人体的经脉还很深，邪不能深入，只能停在表面络脉上。

夏取阳经浅刺；因为夏天是暑病，阳气溢于皮表，故暑邪入的是阳经表面。

秋取俞合；取俞穴以泻阴寒之邪，取合穴以泻阳盛之邪。由于秋季多为阳盛之邪，故多取合穴。

冬取井荥；因为冬天阳气深藏，取合穴会把阳气引出来，所以取荥穴来加强阳气之固表，取井穴来降阴气之逆行。

## 补泻针法

虚则补之，实则泻之。

::: tip 呼吸补泻法
针与气，同进同出为泻，反之为补。

泻法

吸气时进针，这样针与气同进，针就打开了气门。吐气时出针，这样就把邪气带出来了，同时不伤正气；吐气前摇大针孔，边吐气边出针，为大泻；出针后不闭针孔，还用指甲切针孔的边侧，让邪气尽出。

补法

吐气时进针，这样进针不会伤到正气。引到气后，待针下气实了，吸气时出针，这样针下的正气不会被带出来，针出后立即捂针孔，这样从远处引来的正气会冲散本处的邪气，而且正气不伤。
:::
