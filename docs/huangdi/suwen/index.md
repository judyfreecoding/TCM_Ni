### 食物汽化
![An image](/huangdi/suwen/14食物汽化.png)
肺的凉压制心的热只能向下行，传至小肠，小肠的热让大肠中的食物中的水汽化，热汽上升至肺，再由肺输布至全身体表（人体外表有一层厚厚的热汽），这就是阳气固表的来源。直接喝的水，在胃里面就汽化了，因为胃在心和小肠的输热管道的中间，胃也是很热的，所以白水很快就汽化了，而食物中的水份就没有那么快汽化，要到大肠里才有机会汽化。如果心和小肠的温度不够，称为里寒，阳气就不会走表；如果太热，就伤精液，病的呈现就在阳明胃和大肠中，表现为干燥，因为精液没有了，这时就把干燥的食物残渣清掉，精液自己会回来。

### 伤阳的原因
伤阳的原因，寒、暑、湿。久坐湿地伤于肾，湿伤阳之后，头痛如裹。把湿去掉就好了。

第四个伤阳的原因，是气。十二经脉的脉气，如果受了阻，就会导致形肿，这是没有外力作用的肿，就是气伤形，这就是阳气不足了，用一些阳气的药把水湿蒸发掉，就好了。也可能以形伤气，比如撞了，很痛，很快肿起一个包，先痛后肿，这就是形伤气。

阳气一直在行走，如果过于操劳，阳气耗损比生成快，就会不够用，就会因为动能不足而在某一个地方停滞不动，造成昏阙、不出汗、失明等等症状。五官功能减弱或失去，都是因为阳气停滞的原因，比如耳聋就是因为肾阳不足。

生气的时候，需要动用很多能量，造成人体短暂不足，所以常有一生气就昏阙或中风或发心脏病的现象。

五官功能减弱或失去，或全身动作不能做，这都是阳气的问题。

### 疣和疮的产生
疣的产生。汗出来，停在皮肤表面，与空气中的湿气相结合，就形成疣。所以运动一定要带毛巾，随时擦汗，不能让汗长时间停在皮表与湿气结合。如果汗湿了衣服，汗和衣服上的湿长时间相结合，更容易长疣，所以汗出要马上换干衣服，不能靠体热阴干。

如果汗出，与空气中的寒相结合，就形成疹痘、疮、脓疡。这就是坐疮的成因。

早上宜运动，晚上不宜运动。

### 营卫

![An image](/huangdi/suwen/15营卫.png)
营指血，卫指气。因为气在体表卫外，所以叫卫。

摸脉，可以感受到脉管内的血和脉管外的气。如果气是刚强的，不好，气应该是柔和的，说明阳气很顺。闭着眼睛摸葱，葱茎是实的，葱叶是虚的，人的脉也是同样的感觉。

中风病人躺两周不翻身的话，臀部就会长褥疮，因为阳气不行，阴就不行，阴停在那里就有很多湿热痰等瘀积，就会烂掉。

风为百病之始。所有的病都是因风带来的，都是先在表再慢慢入里。反过来，治藏病腑病时，慢慢开始显示风证（很浅表的证状），代表病快要好了。

藏管收藏，腑管宣泻。也就是说腑管排泻宣发。藏把好的东西都收藏起来，腑把不好的东西都排泻掉。新鲜食物吃下去，24小时之内一定要完成整个分解吸收排泻的过程，如果没有，食物留在身体里过久，就会变质。收藏和宣泻，都是因为阳气的作用。24小时完不成，就是阳气不够的原因，久而久之，变质的食物累积在身体里各个地方，形成肿瘤等各种病。所以行阳很重要，行阳则阴不积。

### 肚脐对应的四方五藏
![An image](/huangdi/suwen/30肚脐对应的四方五藏.png)
四方定位的规则，也即地图的定位规则，上北下南左西右东。这是站在地形的对面看地形，是这个定位规则。站在人体的对面看人体，也是这个定位规则，上北下南左西右东。
这个定位规则可以用在任何物体上，大到地球，小到一个人，或是人身上的一个部位，如肚脐。

脐东对应肝，脐下对应心，脐西对应肺，脐上对应肾。如果是医者，站在患者对面观察，那么方位原则就是上北下南左西右东；如果是肚脐本人，则是脐左对应肝，脐右对应肺，脐下对应心，脐上对应肾，脐中对应脾。简单记忆就是：左肝右肺，上肾下心。舌诊也是这个原则。

所以脐下有动悸，是心的问题。
动证属风。

脾，在变动为哕（音月）
寒伤血，热伤气。如果贫血，就知其寒，不能再开寒凉药，要开热药，把寒去掉，血才有机会回复正常。

阳盛则身热。如果燥热不出汗，吃了发散药还是不出汗，就洗冷水，寒极生热，就会出汗。

阴盛则身寒。

### 治病的方法：母能令子虚

七十七难，上工治未病。肝有病，知肝传脾，先实脾。这就是上工治未病的意思。

七十五难，东方实，西方虚，泻南补北，金平木也。这话的意思是，东方是木，西方是金，如果东方实的话，说明西方很虚，也就是当肝实的时候，说明肺很虚，因为肺没有办法克木，所以造成木实。泻南补北，金平木也。这时候单靠补土生金以克木，是远不够的，还需要泻火补水，南为火，北为水，火一泻，木必然要救火，而水一补，水又克火，木更需要救火，这样木的实证可解。

这个治证道理适合所有藏，不止于肝。

这个说明也反证了，母能令子虚，子能令母实。子能令母实，是病因；母能令子虚，是治法。

一藏不平，所胜平之。比如肝有问题，要用金来平木。

### 治病的策略如用兵

治病像打仗，病盛时，我们固元气，护胃气，不与病相争，采守势；病弱的时候，我们再取攻势。所以处方常常变动。

夏秋之间的长夏两周，也就是立秋的前后各一周，是脾之王时，是脾气最旺的时候，这是上天打开的治病的时机，此时只管狠狠治病，不必顾护脾气，时机很短，只有两周，门又会关上。时机过了，就要赶紧收手，不能再用原方了。不在王时时，就先采守势，没有胃口就护胃气，便秘就下大便，等病人有胃口了，就攻一次，攻一次就收手，不能贪攻。

病在表，采汗法；

慓悍者，按而收之。慓悍，指巨痛。比如痛风，在痛处选穴下针，在针前方3、4寸沿经按摩，按到针处即出针，再下针，再按摩。反复几次，痛就可以去掉。

其实者，散而泻之。实痛，是24小时不停地痛，拒按，因为它有个东西长在里面，所以不停的痛。散的方法，可以是按摩，也可以下子穴。虚痛，是时有时无的痛，喜按。

阳病治阴，阴病治阳。比如治肝病（阴病），肝病人便秘，所以先通便（治阳明），大便一通畅，肝病就不会进，这时候再去治肝病。

血实宜决之。血实，指血管瘀堵。临床上很多人手臂腿上很多青筋，这就是血实。宜决之，就是放血。在青筋的端头放，如果青筋太多，捡大的放。放了血之后再对症下药，效果会更快更好，如果不放血只下药，治疗见效时间就会比较长。

气虚宜胁引之。用针灸导引。

## 第七篇 阴阳别论（脉论）

正常脉。易经有两个基本，010为坎，101为离。假设1为脉，则坎脉为常脉，也就是脉潜在皮下肉中，也就阴包阳，阳是潜在阴中的。

### 脉与人体的对应

![An image](/huangdi/suwen/35脉与人体的对应.png)
寸关尺，寸指的就是阳，尺指的就是阴。

寸和尺之间是关，关对应的就是横膈，即膈以上为阳，膈以下为阴。寸为君，尺为臣，所以寸应比尺脉宏大一些。

左脉为血，右脉为气。女人以血为本，所以左脉比右脉大；男人以气为本，所以右脉比左脉大。

### 脉的长度和力度

寸正常只能到腕横纹下一点，长9分，如果上到鱼际了，称为溢脉，说明喉咙有病了，溢脉通常不会直直往上，而是向左右歪斜，如果治之后发现溢脉更歪了，说明治错了，如果治对了，溢脉会退回来，退回到正常范围，就是治好了。

寸脉正常为浮滑大，这是与尺脉相比的说法。如果寸脉细，说明阳弱。

尺脉正常为沉涩细，这是与寸脉相比的说法。如果尺脉大，说明阴盛。

尺脉正常为一寸长，如果超出一寸，表示阴太盛了。

### 右关为胃

![An image](/huangdi/suwen/36右关为胃.png)
右关为胃。右手的关脉正对膈，因为胃正在膈的正下方，所以右关代表胃。右关脉，表现的就是胃气的状态。以胃脉作标准，如果寸脉比胃脉小，说明心有问题；如果尺脉比胃脉大，说明肾有问题。

吸入为阴（肝肾），吐出为阳（心肺）。吸和吐中间，就是脾。正常的脉，是一个呼吸跳五次，吸跳两次，呼跳两次，中间还有一个间隔，跳一次。

### 真藏脉

![An image](/huangdi/suwen/37真藏脉1.png)
真藏脉有两种，一为溢脉。就是阴太盛，阴脉把阳脉顶得超过了腕横纹，到了鱼际。

![An image](/huangdi/suwen/37真藏脉2.png)
二为复脉。就是阴脉超出了一寸的长度，向手臂延伸。

真藏脉现的时候，都是极危险的脉（死脉）。表示关已经没有起到隔离的作用了，也就说明膈已经没有起到隔离的作用了。

### 开合杼

![An image](/huangdi/suwen/38开合杼.png)
太阳主开，阳明主合，少阳主枢。眼睛打不开，太阳的问题；眼睛合不上，阳明的问题；眼睛不能眨，少阳的问题。皮肤也是此理。

太阳为表，病从太阳入之后，有两条途径，一是阳明，进了阳明后，病不会再进，所以有的病人阳明病了二十年也照样过，阳明病全是热象；第二条途径是少阳，进了少阳后，就会进一步进入阴经，因为少阳是枢纽，就会出现阴证。

二阳有病发心脾，有不得隐曲，女子不月。二阳就是第二个阳，指阳明。如果阳明胃经有病，无法供给心脾营养，就会得隐疾，男子精少女子没有月经。

三阳为病发寒热，下为痈肿，及为痿厥腨㾓。三阳就是第三个阳，指太阳。正常人的整个背上是寒的，所以称太阳为寒水。

### 金生水和水生木

![An image](/huangdi/suwen/39金生水和水生木.png)
大肠食物中的水份经小肠加热蒸发，上升到肺，由肺降温下降至肾，是为金生水；再由肾汽化，从命门经由督脉上升入脑，供大脑使用。这是最精华的营养，直接供脑使用。

肾的废水排入膀胱，同时其它地方的废水也会经由三焦渗入膀胱，膀胱水经小肠加热汽化，这是第二次蒸熘，水汽直送入肝，供给肝清洁血液用，是为水生木。

膀胱容量是400毫升，正常膀胱是热汽球，热往上升，所以要满了400毫升，才会触动底部开关，产生尿意。尿频，是因为膀胱不够热，冷水往下沉，有一点水就触动底部开关，产生尿意。而且这时候出来的尿因为是冷的，所以没有热汽压力，是滴出来而不是喷出来的。

正常人太阳寒水是保持体温的手段，如果太阳经有病变，寒水没办法透发，寒水就会下沉，所以下面腿会出问题，寒、抽筋、脓疡等。常人脚是热的。

一阳，就是少阳。

### 胆的工作

![An image](/huangdi/suwen/40胆的工作.png)
胆汁是肝的排泄物。心包与心之间有一层水，那是给心降温的。心包与胆之间有一条经络相连，将心的每一下动能传递给胆，将胆汁按压出来，所以胆的喷射频率与心的跳动是一致的。胆汁喷射进十二指肠，是为阳木生阳火。

胆结石的治法。找一种药进入胆，把胆管打开；加强心的力量，让按压力量加大，以便把胆汁喷出来；再找一些化石的药，把石头化小。

一阴，指厥阴。
二阴，指少阴。
三阴，指太阴。

### 鼓脉

鼓一阳为钩。鼓脉，就是摸到寸脉像有一个圆圆的鼓在里面顶着，鼓大约有两三分大小。钩脉，是心脏的脉，代表心脏出大问题了。

鼓一阴为毛。毛脉，就是摸到寸脉像羽毛中间的脉一样，是细细的一条硬脉。这代表肺出了问题。

鼓阳胜急为弦。弦脉为肾有问题。

鼓阳至而绝为石。石脉为肝有问题。

阴阳相过为溜。就是寸脉和尺脉都是忽大忽小，像有什么东西溜在阴阳脉之间，跨过了关的隔离。溜脉就是脾有问题。

### 木生火

身体正常的工作模式：心火进入小肠，肺里的精液进入肾，金生水；大肠里的水汽化进入肺；心藏里的血来自肝，木生火。

常人的手掌是粉红色的。因为上焦心肺的颜色进入手掌，从心肺体积来看，就是很多白加一点红，就是粉红；肝病人因为肝的清洁血液能力变弱，脏血进入心，脏血颜色深，所以肝病人手掌是暗红的。
吃了药，手掌更暗更红，就是治错了；手掌变浅，就是治对了。

### 藏可满不可实

![An image](/huangdi/suwen/41藏可满不可实.png)
藏可满不可实。藏里面充满了精液和阳气（即阳潜在阴中），但不可实，实就是长东西；腑可实不可满。腑里面可以装东西但不可停留，比如便秘，就是食物残渣停留在腑里。

::: info 肝阳不能潜在肝中的证状
肝阳亢，是因为肝里有实，长东西了，肝阳没办法呆在肝里，就只有跑出来，木生火，所以肝阳是跑到心里面，导致心脏跳的速度很快，可以达到一吸九、十至。
:::

::: info 肾阳不能潜在肾中的证状
常人土是制水的。阳应该潜在阴中。肾阳要能潜在肾中，靠的是土来制水。所以如果肾阳不固，不能潜在肾中，出现不能开合的证状（比如不举不射），就强脾，一强脾，不能开合的证状就没有了。水肿，也是强脾，用土去制水。
:::
