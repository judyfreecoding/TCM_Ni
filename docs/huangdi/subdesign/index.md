## 梦能反映五脏盛衰 （出自 72、刺法论）

::: info 梦能反映五脏气虚 出自 72、刺法论
- 肺气虚，会梦见白色之物，或见人用刀斩杀鲜血淋漓，若是秋天时节，此时为肺当令时节，就会梦见战争。
- 肾气虚，会梦见覆船人溺，若在冬季，此时为肾气当令时节，就会梦见躺在水中，心生畏恐。
- 肝气虚，会梦见菌类香木及草生遍地，若在春季，此时为肝气当令时节，则会梦见藏匿树下不敢站起。
- 心气虚，会梦见火中救阳物，若在夏季，此时为心气当令时节，则会梦见被火炙烤。
- 脾气虚，会梦见吃不饱饭，若在长夏，此时为土气当令时节，则会梦见修缮屋顶。

当脏气虚的时候，因为脏为阴，也就是阴虚，就说明阳必然有余。这时就需要适度地调理经脉，以求阴阳平衡。
:::

## 肾

### 肾主水（出自 61、水热穴论）

各种水病都是因肾而起。水病，下为胕肿（足和小腿），中为大腹（腹肿），上为喘气（因为肺中有积水）。肾是根，肺是枝叶，都会积水为病。肺中水盛，造成气上逆不下，气短，使人无法躺卧，这都是因为水汽沿肾经上下而行，居留不去而造成的。所以虽然表症为肺的症状，实际肺没有病，根本是肾的问题。
所以治水的方法，不仅有排水利水，还可以是以下方法：
1、发表。把皮肤表面一打开一发汗，水就从下面排出去了；
2、吐。上面一吐出来，下面水就排出去了；

### 肾为胃之关（出自 61、水热穴论）

肾为胃之关，即肾是消化系统的排水闸门。如果这个闸门紧闭不通，那么消化系统的废水就会聚在肾经上，由肾经进入肺经，再进入皮中，形成水肿，因为肺主皮毛。由于冷水下行，所以水肿大多是脚和小腿。

由此可知，下肢水肿是肾的问题。

## 五脏有余和不足（出自 62、调经论）

所有的病皆由五脏子系统气血不和而生。任一子系统气血不和，该系统的经络就会出现虚弱的点，这些点就是邪入侵的入口。如果子系统气血平衡，则邪是没有机会进入该系统的。五个子系统的气血都平衡，则人不会受病。

治病的核心，在于调理五脏子系统的经脉畅行。

任何一种病，都可以归结到五个子系统中的一个，我们只要把该子系统的经脉调理顺畅，子系统的气血就能达到平衡，病就治愈了。

五脏子系统气血不和，究其原因只有两个，一为有余，一为不足。有余就是多出来了，称为“实”；不足就是少了，称为“虚”。

::: info 神——心藏神——神有余则笑不休，神不足则悲
如果一个人笑不休，说明神有余，也即是心气有余；

如果一个人善悲，说明神不足，也即是心气不足。

这能判断心气有余或不足。人在心气不足或心气有余时，可能会受到外邪的入侵，如果人体五藏安定气血协调，则邪不能深入，只停在表皮，令人汗毛竖起，皮肤有寒冷感。这时可作如下处理：
- 神有余，则点刺中指尖井穴——中冲——放一两滴血，神气自然平稳；或者在中指小指四缝找瘀络放血。
- 神不足，找到心经或心包经皮肤凹陷的位置，按压几下，让气血流动。也可针刺令气血流动，但不可出血，也不可泄气，出针时扪针孔。

如果治善悲，手指按压要针刺的穴位（心经母穴少冲），针只需碰到皮肤表面即可，都不需要刺入皮中，神气就自然充盈了。
:::

::: info 气——肺藏气——气有余则喘咳上气，不足则息弱少气
肺气有余，则喘咳且气往上冲；

肺气不足，则呼吸无力且浅。

有余和不足很容易区别，讲话有气无力，肺气不足；讲话声音大，肺气有余。

肺气有余和不足引起的病，病在初微的时候，面色会有一点发白，称为肺气微泄。

有余则泄之。针刺肺经子穴尺泽，注意不要刺伤经脉，不要出血，不要泄气。

不足则补之。针刺肺经母穴太渊。注意不要出气，出针时扪针孔。
:::

::: info 血——肝藏血——血有余则怒，不足则恐
血一旦有余则肝必郁，所以人易怒；

血若不足，肝必虚，根本原因是肾不足，所以人易恐。

血有余时，则泄胆经，找胆经上有瘀络的地方点刺放血；

血不足时，先找出肝经最细弱的部位，针刺入脉内，久留针，仔细观察，看到脉大了就迅速出针，扪针孔，无出其血。

血不足时，也可针刺肝经母穴曲泉或俞穴太冲，留针，观察太冲脉，针前和针后，太冲脉是有变化的，针下气到了之后太冲脉会变大，待脉变大了就出针。

如果有瘀络，就刺络放血。一般四肢末梢的瘀络，都是刺一下挤出一两滴血即可，就可达到平衡气血的目的。只有对脓疮，才会用拔罐放血。
:::

::: info 形——脾藏形——形有余则腹胀经溲不利，形不足则四肢不用
形有余，则腹胀肚子大，小便、大便不畅；形有余，就是过胖的人。

形不足，则四肢无法自由活动，即手脚没有力量或不灵活。形不足，就是过瘦的人。

脾气有余或不足引起的病，病在初微的时候，肉会有微动的现象，或者会觉得皮下有痒痒的感觉。

形有余则泻其阳。遇到腹胀小便不畅的情况，可以扎胃经子穴历兑。

形不足则补其阳络。遇到四肢不用的情况，可以扎胃经络穴丰隆，行补法。

如果病很轻微，则在膝以下胃经和脾经的中间，找肌肉缝扎一下，让卫气充盈，邪气就会散尽。
:::

::: info 志——肾藏志——志有余则腹胀飧泄，不足则厥
志有余，即肾气有余，则腹胀下利拉肚子；

志不足，即肾气不足，则厥。厥有两种情况，一是昏厥，一是手脚冰冷。

肾气有余或不足引起的病，病在初微的时候，骨节会有动的现象，表示邪在关节部位。

肾气有余时，在然谷找瘀络放血；

肾气不足时，针刺肾经母穴复溜，行补法。
:::

在病刚开始的时候，这时邪还很浅没有深入，立即在有病症的部位浅针（放一点血也行），不可刺入主经脉，病邪能立即去除。

如果病已深入到脏腑，则必须在主经的穴位上下针，才能行运主经气血，此时如果在络上下针，一点用也没有。

::: info 如何理解虚实
前面说过，实，就是有余，就是多出来了；虚，就是不足，就是少了。具体虚实病症是如何产生的，要从三个方面来看：

一、来自空气中的邪引起的虚实病症（称为阳病）

人体里面是没有空余地方的，每一处都充满了气和血，好比每个房间里都住着两个人，这是额定标准。实然从外面挤进来一个坏蛋，中医统称为邪，这时房间里就有了三个人，这就多了一个，称为有余，也称为实。

正常情况下，房间里原来那两个人肯定会想办法赶走坏蛋，结果就是两个：
1、坏蛋赶走了。这是非常好的情况，人不会受病。
2、坏蛋没赶走，房间里的人阵亡了。房间里只剩下坏蛋，从额定两人变为一人，少了，就称为不足，也称为虚。这个过程，通常需要一周。所以，坏蛋刚来的时候是实症，一周以后就变成虚症了。

这是来自空气中的邪引起的虚实病症的演变。处理的思路是，因为来自于空气中的邪，本质上是一个气团，所以，把身体其它地方的正气调过来，正气大军一冲，就把邪气团给冲散了，然后正气再一挤，就把冲散的邪气微粒给挤出皮肤了。

二、来自情绪运行引起的虚实病症（称为阴病）

情绪像代码。一段代码运行了，必然会有结果产生，可能是视频、图片，也可能是一组数据，如果没有显示器显示，那么你看不见它的运行结果，但它的结果数据是实实在在存在的，它们占据了内存空间。情绪也是如此，一段情绪运行之后，必然产生结果，而且其结果也是以气团的形式实实在在地存在于子系统中。

以下是五种情绪运行的结果：五种情绪，人体都需要适度运行，一点点的生气，一点点喜悦，适度的思考，一点点悲忧，一点点恐惧。如果过度，就会导致身体的虚实症。

怒产生的气团，如果一直没有散掉，它会影响气血的正常运行，久而久之，它的周围会聚集一些留滞的气血，这样气与血并在一起的团块，就是肿瘤，称为“实”。所以治疗肿瘤，不仅要行气，还要活血化瘀，才可以把病治好。

五种情绪运行的条件：这里不是指外在条件，比如收到鲜花和祝福是喜悦的条件，这里指身体内部环境支持情绪运行的条件。除了思考，其它四种情绪都不是无缘无故来的，都有其运行条件，条件合适的时候，情绪才会运行。

三、来自饮食引起的虚实病症（称为阴病）

身体里的气和血，都喜暖怕寒，如果吃下寒冷的饮食，会令血流动缓慢甚至局部不动，而气也就随之散去，形成阴虚症。

食物停在肠胃里，不能被正常地消化吸收和排泄，就形成实症。

## 阴阳

阴虚则内热，阴盛则内寒；

阳虚则外寒（就是表皮寒冷），阳盛则外热（就是表皮发热）。

知道了阴阳的虚实规则，可以帮助我们准确地断症和用药。中药有去里寒的药，有去表寒的药，有入阴的药，有补虚的药，断症准确了，药性识准了，才能药到病除。比如对于阴虚内热的情况，可以用滋阴的药、补虚的药、祛热的药合在一起来治疗，如果只用袪热的药，病人的热是袪不掉的，因为内热的原因没有解决，原因是阴虚。一般久病的人，都有阴虚内热的现象。

阳盛则外热。是指上焦不通，皮肤毛孔关闭，汗液无法排出体外，也就不能把体内之热排出去，就发生表热的症状。这种情况，一般是用发表的药，把皮肤毛孔打开，让汗液排出来。比如对感冒发烧无汗就是这样处理。但有一些病人，并非感冒，而是长期出不了汗，这时即便使用大剂的发汗的药可能都没有用，吃下去只发热不发汗，这种情况下可以洗冷水澡，寒极生热，身体内热会源源不断地排汗出来，把毛孔冲开。长期毛孔不开会导致很多累积而致病。

阴盛则内寒。人如果过度劳作，阴气就会上逆致胸，阴寒之气聚留胸中，会致心跳减缓，血行减慢。如果正逢冬天，呼吸进来的空气也是寒的，劳作出汗又会带走身体热量，如此胸中阴寒之气更甚。这就是阴盛生内寒的道理。

阴虚生内热。人过度操劳劳作，消耗了气血，又来不及补充水谷营养，阳气因此不足，造成上焦无法行阳，下焦排泄受阻，于是胃热之气滞留不出，热气熏胸，就发生内热的状况。

阳虚生外寒。阳气不足，则无法达于皮表以驱走外寒，所以会感到皮表寒冷。

## 胸腔

发生在胸腔的病，如何偏于气病，则取肺经；如果偏于血病，则取心经。

## 舌

舌面是肺，舌体是心，舌根是脾，舌下的金津玉液是肾，舌中的筋是肝。如果舌头抽筋，那就是肝的问题。
