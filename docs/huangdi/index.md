# 黄帝内经

《黄帝内经》是中医理论的奠基之作，是中国最早的医学典籍之一，对中医学的发展有着深远的影响。

对于系统工程师来说，《黄帝内经》就是《人体系统设计说明及运维手册》。因此，我的工作，就是把这部《人体系统设计说明及运维手册》用现代语言呈现出来。

《黄帝内经》年代过于久远，许多文字晦涩难懂，我依赖了倪海厦老师的《黄帝内经》白话译本。
