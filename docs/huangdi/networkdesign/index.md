::: tip 选穴法则（出自 58、气穴论）
背为阳，胸为阴，当阴阳不交时，会胸痛彻背背痛彻胸，痛得不能正常呼吸、不能躺下，短气、上气，偏左胸一侧痛，脉满起。
这种情况，刺天突、上纪、下纪及十椎。上纪，即中脘，倪师用巨阙；下纪，即关元。正面扎天突、巨阙、关元，扎了之后，待巨痛去掉了就起针；此时病人背后第十椎会痛（因为前面扎了三穴之后，三焦气会汇在此处），再扎第十椎，把这一点的痛去掉。只需扎一次，就治愈了。

原因：脖子是气海，天突扎一针，是让阴气往下降；关元是小肠（心阳）募，关元扎一针，是让阳气往上升；中间中脘扎一针，是让胃气往下走。如此一来，阴阳气畅通了，胸痛彻背背痛彻胸的症状就会去掉了。
:::

### 365络会穴（出自 58、气穴论）

孙络是最细微的血管，遍布全身。全身体表的孙络也有365个会穴。这些会穴，是营气和卫气的流通出入之处，也是病邪的所入之处。一旦病邪占据于此，营卫因无法流通而滞留，卫气因而流散，营气滞留络脉中，造成血停拥堵，气血一堵，向外会产生热症，向内会令人呼吸短浅。此时立即泻血排堵，让营卫恢复流通。病邪占据点很容易被发现，气血拥堵的络脉是青色的，称为瘀络，只要看到皮表有瘀络，就立即刺络放血，这时就不必管它是属于哪条经哪个系统。

### 365溪谷穴（出自 58、气穴论）

肉之大会为谷，肉之小会为溪。人体亦有365个溪谷穴。溪谷穴，也是荣卫气的流通出入之处。一旦病邪占据于此，荣卫不行，堵塞不通，会令血积脉热，肉腐生脓，内伤骨髓，外损肌肉。大寒之邪积留在溪谷，会令肉卷筋缩，肋部肘部无法屈伸，向内发展为骨痺，向外发展为肌肤麻木不仁。

所以，365溪谷穴，与365络会穴、365气穴相同，凡病邪入体之始，都是先在表脉充斥往来，此时只需微小的针刺，即可去邪。

所以，病邪进入的部位虽然不同，但初始时的治法都是一样的。

## 骨空 （出自 60、骨空论）
人体上有很多穴位属于骨空，也就是骨间的空隙。骨空都是治骨病的地方，即在骨空的位置进针能治疗骨病。

|髓空|脑户、风府、哑门|
|脊骨上空|风府上（风府上面脑骨边上还有一个孔）|
|脊骨下空|长强|
|面骨空|巨髎、大迎|
|肩空骨|臑俞|
|臂骨空|三阳络|
|大腿骨空|中渎、环跳|

## 水俞穴（出自61、水热穴论）

水俞一共57穴，分别是：
1、臀部25穴。命门及以下5穴，左右一寸半（肾俞）各5穴，左右三寸各5穴。共25穴。
2、腹部肾街10穴。即肾经上的中注、四满、气穴、大赫、横骨，左右各5，共10穴。
3、腹部胃街10穴。即胃经上的外陵、大巨、水道、归来、气冲，左右各5，共10穴。
4、足上12穴。三阴交、漏谷、地机、阴陵泉、照海、复溜，左右各6，共12穴。

以上57穴，都是肾经络脉所在，水会客居的地方。可以根据水病的具体症状，随症选用。在水俞穴下针之后，病人会排很多小便出来，这就说明积水排出来了。

## 热俞穴（出自61、水热穴论）

热俞一共59穴，分别是：
1、头热25穴。头上督脉、膀胱经、胆经5行，每行5穴，共25穴。诸阳汇在头上的热，都可以用这25个穴位来治。用得最多的是百会点刺放血。当热往上冲，致人昏迷时，百会一放血，阳就往下走，热就退下来了。
2、胸热8穴。大杼、肺俞、缺盆、膺窗，左右各4穴，共8穴。泻胸中之热，比如肺炎，或心脏问题引起的胸中大热，胸中会很难受，甚至像有烫水倒入胸中的感觉，此时指压这8个穴位，都有压痛，在压痛点下针，效果非常明显。压痛点就是病气堵的地方。实际治病，都是按压痛点来治。
3、胃热8穴。伏兔、足三里、上巨虚、下巨虚，左右各4，共8穴。用于泄胃中热气。消渴症，就是典型的胃热症，渴饮百杯不能止渴，饿食百碗不能止饿。
4、四肢热8穴。云门、肩髃、委中、环跳，左右各4，共8穴。用于泄四肢之热。
5、五脏热10穴。膀胱经上心俞、肺俞、肝俞、脾俞、肾俞，左右各5，共10穴。用于泄五脏之热。

以上59穴，都是能左右热的地方。

热症，是因为人体受到外来寒邪所伤，寒太盛了就会生热。
