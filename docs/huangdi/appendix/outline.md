一、系统总体设计

![人体系统总体设计图](/system_design_overview.png)

人体系统架构设计说明。
- 基础理论层。阴阳为人体系统实现和运行的基本原理，不止人体系统，整个世界都是基于阴阳思想实现和运行的。阳负责提升增加，阴负责减少降低，阴阳合力，才能使事物维持动态平衡。在温度上，阳负责升温，阴负责降温；在速度上，阳负责增速，阴负责减速；
- 基础层。落实到生命系统，阴阳具体实现为气血。气是阳的实现，血是阴的实现。在基础层，阴阳就不再是概念，而是具体的物质：气和血；
- 服务层。
  - ** 人体系统由五个子系统组成：肝心脾肺肾。五个子系统仍然遵循阴阳的设计规范，肝系统的阴由肝实现，阳由胆实现；心系统的阴由心实现，阳由小肠实现；脾系统的阴由脾实现，阳由胃实现；肺系统的阴由肺实现，阳由大肠实现；肾系统的阴由肾实现，阳由膀胱实现。
  - ** 在五行中，肝代表木。肝主风。在四季，肝对应春。在方位，肝对应东。在味道，酸入肝。在气味，肝味臊。在情绪，肝主怒。在声音，肝音嘘；其畜鸡，其谷麦，其果李。肝主筋。久行伤筋劳于肝。肝主语。肝开窍于目。肝其华在爪甲。在变动为握。肝病发惊骇。怒伤肝，悲胜怒。风伤筋，燥胜风。酸伤筋，辛胜酸。肝上有邪沉于两腋。肝藏血，血舍魂，魂聚则为神。肝气虚则恐，实则怒。诸风掉眩皆属于肝。女子以肝为本。
  - ** 在五行中，心代表火。心主热。在四季，心对应夏。在方位，心对应南。在味道，苦入心。在气味，心味焦。在情绪，心主喜。在声音，心音嚯；其畜羊，其谷黍，其果杏。心主血脉。心开窍于舌。心开窍于耳（耳兼心肾）。心开窍于目（主要在眼角，因为小肠经走眼头和眼尾），久视伤血劳于心。心其华在面。在变动为忧。心病及五脏。喜伤心，恐胜喜。热伤气，寒胜热。苦伤气，咸胜苦。心肺有邪沉于两肘。心主神志。心主汗。心藏脉，脉舍神。心气虚则悲，实则笑不休。诸痛痒疮皆源于心。
  - ** 在五行中，脾代表土。脾主湿。在四季，脾对应长夏。在方位，脾对应中。在味道，甘入脾。在气味，脾味香。在情绪，脾主思。在声音，脾音呼；其畜牛，其谷稷，其果枣。脾主肉。久坐伤肉劳于脾。脾主四肢。脾开窍于口。脾其华在唇。在变动为哕。脾病发肌肉。思伤脾，怒胜思。湿伤肉，风胜湿。甘伤肉，酸胜甘。脾上有邪沉于两胯。脾藏营，营舍意。脾气虚则四肢不用五脏不安，实则腹胀经溲不利。诸痉项强皆属于湿，诸湿肿满皆属于脾。
  - ** 在五行中，肺代表金。肺主燥。在四季，肺对应秋。在方位，肺对应西。在味道，辛入肺。在气味，肺味腥。在情绪，肺主忧。在声音，肺音呬；其畜马，其谷稻，其果梨。肺主皮毛。肺主一身之气。久卧伤气劳于肺。肺主治节。肺开窍于鼻。肺其华在毛。肺通调水道。在变动为咳。肺病发背部。忧伤肺，喜胜忧。热伤皮毛，寒胜热。辛伤皮毛，苦胜辛。心肺有邪沉于两肘。肺藏气，血舍魄，魄聚则为精。肺气虚则鼻塞不利少气，实则喘呃胸盈仰吸。诸气愤郁皆属于肺。行寒饮冷伤肺。
  - ** 在五行中，肾代表水。肾主寒。在四季，肾对应冬。在方位，肾对应北。在味道，咸入肾。在气味，肾味腐。在情绪，肾主恐。在声音，肾音吹；其畜猪，其谷豆，其果坚。肾主骨。久立伤骨劳于肾。肾主脑。肾开窍于耳及二阴。肾主二便。肾为胃之关。肾其华在发。在变动为栗。肾病发关节。恐伤肾，思胜恐。寒伤血，燥胜寒。咸伤血，甘胜咸。肾上有邪沉于两腘。肾藏精，精舍志。肾气虚则厥，实则胀五脏不安。诸寒收引皆属于肾。心如悬若饥状，是肾的病候。强力举重久坐湿地伤肾。房事伤肾。
  - ** 五个子系统遵循相生关系。即木生火，火生土，土生金，金生水，水生木。相生关系，确定了母子关系。如木生火，则木为火之母，火为木之子。相生关系应用于系统维护中，即为：虚则补其母，实则泄其子；子又能令母实，母又能令子虚。
  - ** 五个子系统遵循相克关系。即木克土，土克水，水克火，火克金，金克木。相克关系应用于系统检修中，见效很快。
- 网络层。五个子系统分别有自己的网络。由于五个子系统分别有阴有阳，所以各自有阴阳两个网络，都包含主干线和毛细网络，连接服务器和身体各部份。五个子系统共计十个子网络。另外，心系统因为其特殊职能和地位，另为其设计了外围的防火墙系统——心包系统，心包系统也包含阴阳，心包为阴，三焦为阳。合计十二个子网络，其主干线称为十二正经，具体为：肝经、胆经、心经、小肠经、脾经、胃经、肺经、大肠经、肾经、膀胱经、心包经、三焦经；
- 协作层。十二个子网络都遍布身体系统，在终端相互盘绕协作。
- 应用层。人体的消化吸收、运动、表情、思维、情绪、说话等功能表现。

三、系统运行设计

1、 寒热表现

人体系统时刻处在动态平衡的维持中。打破平衡的最常见因素是寒，因为人体温度通常高于环境温度。对于寒的入侵，人体的处理办法通常是加热，所以反过来，一旦人体某个脏器热了，说明那里有寒入侵了。脏器发热，有它的外在表现：

肝上有热左颊（颧骨一带）赤，肺上有热右颊赤，心上有热额（指前额眉间这一带）先赤，脾上有热鼻先赤，肾上有热两颐赤。两颐指耳门听宫听会颊车这一带。

以上五个热象表现是脏器发热的先兆，可以通过针刺井穴（或沉邪点）放血来阻止问题的进一步深化。其它的身体异常表现，无论寒热，都是因为寒，需要用补阳、加热、贯通阴阳等方法来解决，而不能简单地用泄热降温消炎来解决。

2、特效设计

人体系统运行过程中遇到的每一个问题，都有多种解决办法，如此，才有利于系统自我修复。但是，设计师为人体系统的五个子系统分别设计了特效的解决方法。
- 肝：揉宗筋
- 心：放血、揉脖子（放血是一种方法，具体放哪里的血要看具体问题，否则放了也没用）
- 脾：灸肚脐、揉肚子
- 肺：拔肛门
- 肾：捏睾丸、拔肛门

四、故障解除逻辑

在说明故障解除逻辑之前，需要先申明几个概念。

- EP （Error Point）报错点。 EP 指在没有任何外力作用的情况下，自主产生的报错，包括痛、痒、麻、热、肿胀等等。EP 的成因多是炎症，炎症的原因又多是细菌病毒，细菌病毒这类微生物在中医理论中被统一称为“邪”。

- DP （Debug Point）调试点。 狭义的 DP 指对于压力有反应的点，最常见的反应是压痛或酸胀。广义的 DP 除了压痛，还包括没有不适反应但有外形变化的点，比如色块、色点、小丘疹、结节、硬块、明显的瘀络、鼓包、凹陷等。把 DP 的异常清掉（比如揉到不痛），就能令 EP 的报错自然解除。

- 三网关（Gateway）。这三个网关对身体系统其它部位的流速流量都有明显的影响和调控作用，是故障解除的关键。同时，三个网关具有相互调控、相互修复的能力。

  - ** 顶网关（Top Gateway）。指颌骨下沿线及颅骨下沿线，以及整个脖子。以颌骨下沿线为例，气血流过颈项，上行至颌骨，要经过两个小于90度的急弯转折，才能继续上行至面部。这两个急弯转折，就是容易减速拥堵的地方，连带地，颈项的流速也会降低，所以这一带是垃圾数据沉降的地点。垃圾数据，以情绪数据为主，形式主要是气泡。清除顶网关沉降的垃圾数据，前面对面部、胸腹部的报错有明显地收敛作用，后面对后头、背部的报错亦然。另外，脖子是全身血脉最集中且肌肉最浅的地方，心主血脉，以脉治心，所以揉脖子等于按摩心脏。指尖稍用力压揉顶网关，仔细体会指下，能感觉到咕嘟咕嘟或咯噔咯噔的气泡滑动，有时会有压痛，有时不会，把气泡揉开。

  - ** 上网关（Upper Gateway）。指肩关节，包括锁骨、肩胛骨，以及臂锁、臂肩关节缝。上网关对于手部和臂部的报错有明显地收敛作用。
  
  - ** 下网关（Lower Gateway）。指髂骨上沿线及耻骨上沿线，以及它们所包围覆盖的整个下腹部和臀部。下网关位于人体的中心位置，是人体阴阳交换的位置，也是人体总共20条经脉中的15条经脉所过之处，同时是人体全部筋的总管之处（人体的筋的状态决定人体的行动能力）。因此下网关在人体系统修复中具有非常明显的战略意义。下网关以髂骨耻骨上沿线为主。髂骨耻骨上沿线是人体腰部一条横围的线圈，后高前低。沿着髂骨耻骨上沿线布有一条脉线，叫带脉。倪海厦称，临床上看，带脉有三条，一条是沿着髂骨耻骨上沿线布的，一条是横围肚脐命门一圈的，还有一条是界于这二条之间的。本文称的带脉，指沿着髂骨耻骨上沿线布的脉线。经脉在流经横突骨沿的时候会遇到阻力而放缓流速，因而这条髂骨耻骨骨沿是垃圾数据沉降的地点，垃圾数据，以情绪数据为主，形式主要是气泡。清除下网关沉降的垃圾数据，对上至胸腹下至腿脚的流量流速都有明显的影响作用，能快速收敛相关的报错。在这条髂骨耻骨骨沿上，密布着众多的重要穴位：曲骨、横骨、气冲、髀关、带脉、五枢、维道、大肠俞、腰阳关。在曲骨、横骨、气冲、髀关、五枢、维道位置，还布有筋的总管——宗筋，宗筋对于全身的筋具有调控、管理、修复能力，是修复人体行动能力的重要位置。肝主筋，以筋治肝，所以这里也是修复肝的重要位置。这里沉降的情绪数据通常比较大，手指深压，往往指下能感觉到硬的气团，伴随有明显压痛。把气团揉散，相应的报错会有明显收敛或解除。因为下网关面积范围大，所以一般用肘揉，或用工具揉。



故障解除逻辑一：DP 寻址逻辑（适用于 EP 明确的情况）

第一步，精准确定 EP 位置和 EP 所处的经脉线路。

要以人体系统经脉走线为标准确定 EP 位置，而不是模糊地以头、手、腿等作描述依据。可以通过精细化地询问患者达到精准定位的目的，如果患者描述不清楚，可以上传照片，并在照片中圈注 EP 位置。

第二步，找到 DP 。

- 在离 EP 最近的 Gateway 沿经脉线路找 DP ，主要是找压痛点。
- 把离 EP 最近的沉邪点作为 DP 。

第三步，在 DP 调试，直到 DP 正常。

- Gateway 上的 DP ，通常采用点揉的手法，或针刺，目标是使 DP 的压痛消失。一旦 DP 的压痛消失，通常 EP 也就随之消失了。比如手腕小指侧关节痛（痛在小肠经上），则在同侧肩胛骨及臂肩关节缝上（小肠经沿线）找压痛点，找到后把它揉到不痛，手腕关节就不痛了，而且好得很彻底。
- 对沉邪点的操作，通常有放血和拍痧两种方法。如果 EP 与心系统相关，多采用放血方法；否则采用拍痧方法。

第四步，DP 正常后，检查 EP 是否消失？

- 是。修复完成。
- 否。回到第一步，再次循环本流程，再次确立新的 DP 。





- 重病都加拔肛门
- 肺。肺气实：肺与膀胱别通、气会膻中；肺气虚：肛门；肺寒：大肠募天枢、大肠俞；水道：肺募云门；综合：肺俞、肺原太渊
- 脾。四肢肌肉问题：肚脐；其它问题：脾俞；湿：髀（胯骨沿儿或腹股沟）；热：历兑、隐白；
- 心。热：肘窝；寒：脖子、宗筋；堵：龙胆泻肝丸
- 肝。
- 肾。

DP 处理目标（把结节硬块揉散化开）和处理方法（揉、捏、重按轻提）

- 排气。
- 拔脓。

故障解除逻辑三：适用于没有具体的 EP 的情况。

- 获取完整的症状表现。患者报错时往往只说他当前最紧急的那一个症状，但这是不够的，需要引导他说出更多的症状，我们才能精准地判断问题所在。引导询问的依据是《系统自检报告》和《系统总体设计》。

案例一：患者走路步履蹒跚。从系统总体设计中，我们知道肾主骨，说明他的肾有问题，那么是肾阴有问题还是肾阳有问题？不知道。但通过系统总体设计我们知道肾主二便，所以可以问他：大便如何？他答：便秘。问题确定：肾阳虚。
案例二：患者手臂上大面积长皮炎。从系统总体设计中，我们知道肺主皮毛，说明是肺的问题，但是是肺阳的问题还是肺阴的问题？不知道。但通过系统总体设计我们知道肺与大肠相表里，所以问：大便如何？他答：便秘。再问：便秘肚子痛不痛？答：不痛。问题确定：肺阳虚。
案例三：患者胃痛15天，这15天当中，没法吃饭。常识告诉我们，这15天当中，他肯定已经尝试了多种治疗办法，均告无效。所以肯定不是胃的问题。问：胃痛是如何产生的？答：喝了一杯冰啤酒就痛得不行了。思考：正常情况下，不可能喝一杯冰啤酒就痛得不行，所以喝之前一定有伤胃的事情发生。系统总体设计说，木克土。伤胃的事是肝干的。肝要受了伤才会去克胃。系统总体设计说，怒伤肝。所以猜测是喝酒前生了气了。再问：痛在一天当中有没有起伏？答：有，半夜最痛。《系统自检报告》说，半夜11点到1点是胆经扫描报错时间，1点到3点是肝经扫描报错时间，所以半夜最痛。问题确定：肝瘀堵引起的胃痛。

- 如果 EP 在四肢或头部，且 EP 是一个片，说明问题出在协作层，就需要在服务层去找错误源，把错误落实到具体的脏或腑子系统。落实了问题子系统后，就可以分三个方向考虑解决方案。一是原穴、八脉交会穴、八会穴、俞合穴、募穴、郄穴、络穴；二是沉邪点；三是最近的网关。在以上三处找 DP。在最痛的 DP 下针，或点揉到不痛。
