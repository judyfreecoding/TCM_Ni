# 2026-08-09 开发日志

## 任务：从总体设计.docx 还原系统总体设计图并嵌入 outline.md

### 背景

`docs/huangdi/appendix/总体设计.docx` 中有一张人体系统分层架构设计图，需要将其提取并嵌入到 `docs/huangdi/appendix/outline.md` 的"一、系统总体设计"部分。

### 技术难点

- docx 中的图片（image1.png）内容在工具链中无法直接查看
- 只能通过解析 Word 文档 XML 结构来重建图的布局
- Python 2.7 + matplotlib 2.2.5 环境，有编码和 API 限制

### 方法

1. **解包 docx** — docx 本质是 zip 包，用 `zipfile` 读取 `word/document.xml`
2. **解析形状元素** — 从 `<wp:anchor>` 和 `<wps:wsp>` 中提取 21 个文字框的精确坐标、尺寸、边框样式、填充色、文字内容
3. **提取主题配色** — 从 `word/theme/theme1.xml` 获取精确的 16 进制颜色值
4. **提取内嵌图片** — 服务层框内含 `image1.png`（1391×913px），经对比度拉伸后嵌入渲染输出

### 关键经验

- **docx 解析策略**：zipfile + XML regex 比 python-docx 更灵活，能精确提取形状坐标
- **Python 2.7 编码**：所有中文字符串必须用 `u"..."` 前缀，否则 matplotlib 会抛出 `ValueError`
- **主题色提取**：`a:srgbClr` 不出现在形状中，需要通过 `theme1.xml` 查找 `a:accentN` 等名称对应的实际色值
- **边框判断**：`<a:ln>` 内的 `<a:noFill/>` 表示边框不可见，非线宽为 0
